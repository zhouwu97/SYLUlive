# 本机主题包与主题商城

共享内容卡片的 `tint`／`glass` 填充在 `AppCardSurface` 与 `AppCard` 中使用相同染色规则，开关毛玻璃不改变染色结果；警告等显式语义底色保持原色。卡片底色不透明度在设置、工坊、预览、导出与导入中统一使用 0–100%，不叠加最低不透明度；文字、图片和主题淡底图不随底色变淡。自定义页头的信息卡采用同一描边、阴影与染色，底面保持不透明，避免人物图干扰资料和学期文字。

平板侧栏模式下，首页、校园和我有装饰时使用沉浸页头。Hero 从所属内容栏顶部铺到锚点下方，沿用手机渐隐并裁切在栏内，校园随内容栏宽度增加页头高度以保留人物头部。课表壁纸填满课表区域，横屏优先使用 `landscape`。今日概览与周网格之间及外缘露出壁纸，容器使用共享主题卡片材质，课程卡使用主题色板和 `courseCardText`。

主题设置实时预览、全屏九页样例、导入应用效果、工坊和 1080×2340 明暗导出共用沉浸页头绘制。首页顶栏和搜索框叠在 hero 上，校园和我的信息卡压在底边。预览显示主题底栏图标、首页顶栏图标和发帖按钮角饰。

从「我的 → 个性主题」或「界面设置 → 主题 → 编辑主题」进入主题设置。实时预览支持全屏查看九个页面的样例，点击预览中的组件可以跳到对应编辑项。颜色、背景、卡片与页头、底栏、图标与字体、主题包从同一页进入。右上角「应用」直接保存修改过的 App 外观分组并复制引用素材到受管目录，不生成预览图或安装主题包；失败时保留当前外观和草稿并可重试。系统明暗、字号和手势在设备外观偏好中设置，桌面启动图标在主题包分类中单独设置或随主题包导出。

工坊的空态和失败样例复用共享状态插画，分别读取主题的 `illustrations.empty` 与 `illustrations.error`；加载进度和权限图标保留原语义。商城列表在已安装版本与目录版本相同时优先使用本机明暗预览图，本机图片读取失败时加载在线预览；目录更新后使用新版本的在线预览。

工坊中的底栏样式只保存到本机，导出的主题提供配色、图标和着色方式。导航设置的预览、入口摘要、强度和预设按实际生效效果显示，预览同时读取主题图标。选择液态效果预设会保留主题配色与图标，手动关闭后使用普通悬浮导航。

主题设置的主题包分类、本机主题列表与主题商城均提供离线内置的「默认主题（经典）」，恢复主题商城上线前的原始明暗配色、纯色背景、默认字体、卡片与页头布局。商城将内置、官方和社区主题放在同一网格，每款主题只展示一次；经典主题支持名称搜索与浅色、深色、明暗自适应、简约、纯色筛选，无需登录或下载，在线目录加载、断网或商城关闭时仍可应用。经典主题恢复默认液态玻璃导航；设备明暗、字号和桌面图标／小部件选择继续独立保存。切换后编辑器同步载入实际外观；「恢复上一个外观」可撤回，重启后保留选择。编辑起点菜单也可从经典默认主题开始制作。

只有导出、分享或投稿才生成 1080×2340 明暗预览图；两种导出入口共用 JPEG 编码，按体积降低质量至单张不超过 2MB，编辑稿导出继续执行完整主题包校验。导入图片校验错误会显示体积上限或实际尺寸。

主题包分类提供本机主题、导入、编辑稿导出、当前外观导出、恢复上一套外观、主题商城和我的投稿。文件后缀为 `.sltheme`，ZIP 格式及基础字段遵循[格式契约](../../../../docs/design/theme-pack-contract.md)。商城支持浏览搜索、按版本化 `packageUrl` 断点下载与 SHA-256 完整性核对、跨页面试用、更新检查、分享深链（`sylulive://theme/<familyId>` 与 `https://sylulive.online/theme/<familyId>`）、举报、投稿撤回与管理员审核/下架。导入支持选择文件和 Android/iOS 系统文件关联。审核入口在「管理员面板 → 审核待办 → 主题审核」，作者个人主页展示其作品。

应用分组开放全部十组：配色、圆角、壁纸、卡片材质（含 `cardStyle` 描边宽度与阴影）、导航栏、字体、桌面小部件、桌面图标（`launcherIcon` 默认不勾选）、页头布局（`home`、`campus`、`me` 的对齐、沉浸页头高度和无装饰时的标准／紧凑排版）、页头装饰（明暗独立的背景图、颜色矩阵调色及最多 5 张贴纸）。导入、商城应用与用户试用默认选择除桌面图标外的全部分组，主题缺少的分组恢复该组默认值，避免旧壁纸、字体或装饰残留；取消勾选才保留当前设置。试用和应用保留设备底栏样式、画质、强度和材质。手机主壳按当前明暗下的背景或贴纸自动使用沉浸页头。配色应用会把课表文字色和课程块颜色同步为跟随主题；随后手动调整保存在当前外观中，重新应用主题会重置，撤销可恢复。设置页、工坊和导出读取最终生效值。深浅配色跟随原有明暗设置，文字大小独立保存。全局试用会话通过顶部常驻横条跨页面生效，不写入任何偏好存储，进程退出后自然恢复原外观。外观设置页“布局与装饰”二级页支持直接修改卡片样式、三个页头模板与装饰并按槽位或分组重置；更换页头背景保留贴纸，手动调整卡片材质不清除 `cardStyle`。恢复上一个外观会交换两份完整快照；恢复手动外观使用现有手动偏好，且不改动已生效的桌面图标；内置默认主题的构建中该按钮为「恢复默认外观」，回到首次启动载入的主题（不含桌面图标与小部件分组），并可用「恢复上一个外观」撤回。

试用期间调整底栏、卡片材质、课表颜色、壁纸或页头，仅修改当前试用会话；结束试用丢弃这些调整，点「应用」才保存，并把暂存资源转换为已安装资源。已排队的试用修改不能在会话结束后写入正式配置。切换效果预设保留本次试用的自定义数值；切换主题与试用按用户发起顺序处理，旧操作不能结束后发的试用。

“导出当前外观”基于当前最终生效的混搭参数与引用资源重新打包，试用中导出的是正在预览的外观，导出本身不应用主题。生成新的主题 ID 与 1080×2340 明暗预览图，支持系统分享和保存文件，导出产物可直接重新导入。系统文件关联在信任边界限制 48MB 体积并复制到受管临时目录 `incoming-theme/`，完成读取、取消或被新请求取代后自动清理，迟到的旧异步结果不会覆盖当前页面或应用旧主题。

主题商城 Beta 构建可由 Android 发布脚本打包授权的明风主题。首次启动时复用本机主题包校验与安装链路，为尚未保存主题外观的设备离线应用明风。加载失败时显示重试，应用成功后中文提醒可直达「界面设置 → 主题 → 恢复上一个外观」。恢复结果随外观保存，重启继续生效。自动应用仅保存 App 内外观。

ZIP／JSON 在工作 isolate 读取，实际解压输出上限 96MB，读取条目执行 ZIP 原生 CRC 校验，不另加资源哈希。图片先查尺寸再完整解码，只允许静态 PNG／JPEG／WebP。壁纸槽位、沉浸页头随主壳页签在提交切换的同一帧切换，不做淡入淡出；主壳预解码当前明暗的全部壁纸槽位与沉浸页头图，切页首帧即可画出；壁纸与页头背景按显示物理宽度缩放解码，亮度／对比度／饱和度在渲染时使用 `ColorFilter.matrix`，遮罩使用当前 `background` Token 透明度合成；正式页头装饰区包裹 `IgnorePointer` 与 `ExcludeSemantics`，不遮挡资料或按钮交互。字体在校验边界检查必需 SFNT 表并用临时家族名试加载，应用与冷启动首帧通过 `FontLoader` 注册 `theme_font_<id>_<version>`，等宽字体保持不变；桌面小部件通过 `widget_app_palette_v1` 与 `coursePalette` 跟随 App 主题明暗配色；Android 桌面图标通过后台 `activity-alias` 与 `MY_PACKAGE_REPLACED` 安全切换，支持自定义主题快捷方式及 MIUI／HyperOS 权限引导（维护者备选图标源图合入前仅打包 `default`），iOS 接入 `setAlternateIconName`。

主题目录为应用 documents 下的 `themes/`。安装先写 `.staging/`，完成后 rename 到 `installed/<id>/<version>/`，索引只列每个 ID 的最新版本。所有写入复用 ThemeProvider 原有外观队列。当前外观、上一个外观、试用会话和手动壁纸偏好引用的文件均受保护；删除主题只移出列表，失去全部引用后清理旧版本。

Android 10 起，商城下载、首次从其他位置安装和本机主题的「保存」把公开副本放在 `Download/沈理校园/主题/`。「本机主题」打开、回到前台或下拉刷新时读取该目录。由其他应用复制进来的文件可通过「授权读取」一次性授权该目录。点击文件可以预览、试用或保存并应用。公开副本独立于已安装主题，移除本机主题后仍可从文件夹再次导入。

验证入口：`flutter test test/theme_pack --concurrency 1`。已有表情包导入器复用同一条有输出上限的 ZIP 条目读取函数，修改时同时运行 `test/features/emoji/emoji_pack_importer_security_test.dart` 和 `emoji_pack_import_flow_test.dart`。真实渲染截图写入忽略提交的 `client/build/theme-p1-qa/`，不提交 Golden 或二进制夹具。
