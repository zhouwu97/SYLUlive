# ADR-003：免费表情商城与独立创作者权限

- 状态：已接受（Accepted）
- 日期：2026-11-02
- 决策依据：维护者在产品设计评审中确认“全部免费”，并授权按创作者申请、逐包审核和自动缩略图方案实现。
- 实施入口：[实施方案](../emoji-creator-store-plan.md)

## 决策

1. 所有用户可在本机导入、命名、整理个人标签、启停和删除表情包。导入本身不上传；发送图片复用既有上传与消息授权。个人标签不作为公开标签上传。
2. 创作者权限独立于普通用户和管理员角色。申请通过后开放投稿；申请、恢复、拒绝和暂停均由现任管理员处理，不能处理自己的申请。权限暂停阻断新投稿和新作品通过，不自动删除自用副本或已上架内容。
3. 表情商城全部免费，不加入价格、订单或支付流程。官方出品和审核后的创作者作品保留不同来源身份。
4. 每个作品及其更新均单独审核。待审内容不可改变已发布的图片、文字、封面或图标；新版本通过前继续提供旧版。已发布版本不可原地修改。
5. 单张缩略图由系统生成，网格使用静态图，点击后展示完整发送图片或动图。创作者选择包内封面和面板图标，提供每张对应文字、公开名称、简介与公开标签；不要求手工打包。
6. 派生图片作为独立展示资源，不改变既有 Manifest 的规范化字节和 Hash 规则。本机安装、旧消息和收藏协议继续兼容。

2026-11-04 补充：按用户对官方动图对应关系的修复要求，已核对素材的「明风 OvO」可显示随客户端内置的原始静态预览；必须同时匹配官方来源、资源 ID 和发送文件 SHA-256。其他表情仍自动生成缩略图；网格保持静态，点击预览和发送保持完整动图。

## 治理与回退

新投稿在服务端入口和最终事务中复核创作者状态。审核事务再次检查当前账号、管理员权限和作品状态。下架停止整包各版本的后续公开下载，作者仍可查看私有内容并撤回；已安装副本不远程擦除。

历史投稿不自动授予创作者权限；历史未审核记录保留并可由管理员按原规则处理。新增投稿要求开通权限。上线与回退按 [运维入口](../../ops/emoji-packs.md) 执行，本 ADR 不授权生产操作。
