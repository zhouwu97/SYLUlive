# SYLUlive 主题制作

槽位、字段和资源规格以 `docs/design/theme-pack-contract.md`（第 2.7–2.9、6 节）和客户端解析器为准；美术与投稿要求见 `docs/design/theme-creation-guide.md`。只沿用用户选择主题后的外观：不改共享 UI、默认主题、字体资源，清单省略 `font`。

## 质量标杆

动手前先解开 `artifacts/themes/` 或用户给出的合格主题包（例如「明风 · 晴蓝 V2」v8），对照它的做法：

- 三个页头都用 `immersive`，`imageHeight` 140–150。页头图约 2000×760，人物在右侧 45–60%，左侧是低细节的天空或留白，给标题和头像。
- 壁纸 1080×2400：浅色渐变为主，只在一角放一个小 Q 版人物，中间 70% 保持干净。
- 角饰、`cardArt`、空态插画都用同一个 Q 版人物的透明贴纸，和页头是同一画风。
- 种子色取自插画主色（发饰、衣服），不是另选一个颜色。

所有素材看起来像同一位画师为这套主题画的一组图。

## 素材：逐槽生成，不直接塞原图

用户给的参考图（动画截图、主视觉、同人图）通常只有几百像素宽，比例也和页头对不上，不能直接入包。按下面的优先顺序取得素材：

1. **忠实重绘原图**（有人物的页头和全屏壁纸首选）：把原图作为编辑底图交给图像工具，要求「人物的脸、眼形、表情、发色渐变、兽耳、姿势、服装和线条保持不变，只高清重绘并扩展画布到目标比例」，在留白一侧补天空或场景。人物来自原画，最像。
2. **按参考新构图**：原图里没有合适的镜头时（例如需要坐着、拥抱、单人），才让模型按参考画新场景。新画的人物容易变成通用 AI 脸，必须走下文的标志物清单和逐项核对。
3. **Q 版贴纸、纹理、图标**：可以新画，同样核对标志物。

原图本身达到下表尺寸且比例合适时，可直接使用。

| 槽位 | 生成规格 | 构图要求 |
| --- | --- | --- |
| 首页页头（明暗各一张） | 21:9 横幅，长边 ≥1800 | 主角在右侧 55%，腰部以上，脸在垂直中带；左侧 40% 低细节天空或留白放标题 |
| 校园页头 | 21:9 横幅，长边 ≥1800 | 人物在右侧 45%，胸部以上，头顶留空；左侧 55% 是场景留白。不做脸部特写 |
| 我的页头 | 21:9 横幅，长边 ≥1800 | 与校园同规则，可换另一位角色 |
| global / secondary / schedule 壁纸（明暗） | 9:19.5 竖图，≥1080×2340 | 浅色或深色渐变，一角放小 Q 版人物，中间 70% 干净 |
| Q 版贴纸（1–2 个） | 方形透明 PNG，≥640 | 白色描边。用于 `ornaments`、`cardArt`、`illustrations`、`me` 页头贴纸 |

生成前先按参考图逐个角色写「标志物清单」：兽耳、尾巴、额前印记、发饰、瞳色、颈饰、服装扣件、道具。这些最容易被模型省掉，写进提示词时注明「不要省略」。同一角色有日常和舞台两种形态时，按参考图里的形态写。

- 从合照里把每个角色单独裁出、放大到 700px 以上，作为额外参考图一起传入。
- 用户给的每张参考图都要用上；多出来的角色（例如只给了一张特写的第三位角色）安排到「我的」页头或贴纸。
- 提示词写清：标志物清单；画面比例；人物所在区域和留白区域；「整个头部、兽耳和发饰在画面内，头顶留白」；「不要文字、logo、水印、UI」；「忠实于参考比好看更重要」。所有槽位共用同一段画风与配色描述。
- 先生成一个小贴纸核对角色，标志物都对了再批量生成其余槽位。

- 在 Codex 中直接调用图像生成工具。
- 在 Claude Code 等其他代理中，用命令行调用 Codex，每张图一次：

```powershell
codex exec --skip-git-repo-check -s workspace-write -C D:/art/kaguya -i D:/art/kaguya/ref-a.webp -i D:/art/kaguya/ref-b.webp -o logs/home.last.txt - < prompts/home.txt
```

提示词里写明「调用一次图像生成工具，把生成的 PNG 复制到 `D:/art/kaguya/gen/home.png`」。同时最多跑两三个，避免拖慢本机和虚拟机。

角色身份有疑问时（用户说「人物不像」、多个形态、合照），先按 [角色核对流程](references/character-art.md) 确定每个角色的参考图。

## 画质门槛（逐张检查，不过就重做）

1. **尺寸**：页头长边 ≥1800，壁纸 ≥1080×2340。不放大低清图凑尺寸。
2. **头部完整**：按页头实际比例（约 2.6:1，cover 裁切后）看，头顶、发饰、耳朵都在画面内，并有余量。
3. **主体位置**：人物脸不落在左侧标题区，也不被状态栏或搜索框盖住。
4. **同一套**：画风、光线、饱和度一致；不出现动画截图和插画混用，也不出现与主色冲突的大块高饱和色（例如冷色主题里的大片橙光）。
5. **角色**：把成图和参考并排看，标志物清单逐项打勾（兽耳、尾巴、额前印记、发饰、瞳色、服装、道具归属），人数和互动对。缺一项就重做，不靠「整体像」放行。
6. **贴纸**：透明边缘干净，缩到 48px 仍能认出是谁。

## 清单

在独立目录准备 `manifest.json`、两张 1080×2340 明暗预览和引用资源，新作用新 UUID。

- `layout.home/campus/me`：`immersive`，`imageHeight` 140–160，`focalX` 取人物脸所在的横向比例（约 0.6–0.75），`focalY` 约 0.4。
- 明暗各给 `seedColor`（取插画主色）、`wallpapers`（global、secondary、schedule）、`decorations`（三个页头）、`componentOpacity` 0.85–0.9、`frostedGlass` `{enabled: true, strength: 0.2}`、`cardStyle` `{fill: tint, borderWidth: 0.75, shadow: soft}`、`cardArt`（Q 版贴纸，opacity 约 0.14）、`ornaments`（campusHeader、campusNotice、campusServices）、`illustrations.empty/error`。
- 底栏图标、服务图标只在有成套设计时提供；用字体图标批量画出来的通用图标不如不给。

在 `client/` 下打包。脚本复用 App 的配色推导、清单解析、打包和对比度检查，只给 `seedColor` 也能补全 token：

```powershell
flutter test --no-pub --dart-define="THEME_SOURCE=D:/art/kaguya" --dart-define="THEME_OUTPUT=D:/art/kaguya-v1.sltheme" ../skills/sylulive-theme/scripts/build_theme_test.dart
```

## 虚拟机验收

按 [组件与虚拟机验收](references/component-qa.md) 执行。最少要有这几张实拍：

- 首页顶部（页头人物完整、标题可读）和向下滚动后的信息流；
- 校园页、我的页；
- 课表（有课程时最小一行字可读）；
- 一个二级页（壁纸效果）；
- 深色模式下的首页。

每张实拍按「画质门槛」再看一遍；页头头部被裁、标题压在脸上、底纹抢字，就改焦点或重做那张图，重新打包导入后重拍。交付包、实拍和素材说明：哪些是 AI 按参考图新生成的、参考图来源、哪些是用户原图。
