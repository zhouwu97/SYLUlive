# 隐私数据台账

> 本台账描述当前代码和迁移期生产边界。配置开关可能使兼容能力处于退役、迁移或测试状态；发布前应结合生产配置复核，不以 README 单独替代审计。

## 数据分类

### App Account Data

| 数据 | 来源 | 用途 | 位置 | 风险与边界 |
| --- | --- | --- | --- | --- |
| Email、App 密码哈希、登录会话 | 用户输入 / 认证流程 | 注册、登录、找回密码 | Go 服务端 PostgreSQL | 认证高风险；验证码明文不落库 |
| 成功登录流水与设备来源摘要 | 登录成功后的服务端记录 | 调查异常成功登录、识别管理员新设备 | PostgreSQL `account_security_audit_logs`、`security_events` | 仅账号 ID、请求 ID、时间及 HMAC 摘要；不保存明文 IP、UA、安装标识、密码或令牌；设备摘要是可伪造观察信号 |
| 待处置安全预警的来源 IP 密文 | 服务端可信代理边界解析的请求来源 | 管理员调查预警、离线查询大致归属地 | PostgreSQL `security_events.source_ip_ciphertext`，90 天 | 仅需处置预警记录 AES-GCM 密文；使用安全 HMAC 密钥派生独立加密用途密钥；管理员接口按需解密，普通用户、通用模型 JSON 和外发告警邮件不返回 IP；国家／省市仅在本地离线库查询，不发送给第三方；历史摘要不能还原 |
| 昵称、头像、资料、角色 | 用户输入 / 管理流程 | 社区与账号展示 | Go 服务端 PostgreSQL | 按账号注销、治理和资料更新规则处理 |
| 帖子、评论、私信、集市内容 | 用户输入 | 社区、交易、组队和治理 | PostgreSQL、受控上传存储 | 按公开范围、删除和申诉流程处理 |
| 设备安装标识、推送 Registration ID | 客户端 SDK | 推送、设备会话和设备归属 | PostgreSQL、设备本地 | 可关联设备；注销或关闭推送时清理 |
| 收到的点赞记录 | 既有点赞表与公开社区资料 | 查看谁赞了自己的帖子和评论 | 服务端查询、页面内存 | 仅登录者自己的内容；只返回点赞者公开 ID、昵称、头像与内容摘要，取消点赞或内容不可见后不展示 |
| 回复通知已读回执与系统 ID 映射 | 服务端已读接口、推送到达回调 | 清理系统通知、抑制延迟到达的已读回复 | Android 私有 SharedPreferences | 按接收账号隔离；每个账号最多保留 2000 条通知 ID 和回复 ID，以及全部已读水位；系统 ID 映射仅含接收账号、通知／回复 ID 与记录时间，最多 2000 条、30 天，到期在读写时清理，消费或系统通知移除时删除；无消息正文和凭据，清除应用数据或卸载后删除 |

### Local Academic Data

新版客户端正在将个人教务访问迁移到设备侧。个人教务数据原则上在客户端的安全存储、本地数据库或缓存中处理，并由客户端直接连接学校系统。

| 数据 | 来源 | 当前目标位置 | 边界 |
| --- | --- | --- | --- |
| 学号、学校账号、学校密码 | 用户输入 / 学校系统 | 设备 Secure Storage / Keychain / Keystore | 不进入普通 App API、日志、RAG、MCP、队列或备份 |
| 学校 Cookie、Token、个人会话 | 学校系统 | 设备侧学校客户端会话 | 仅限对应 LocalSchoolProfile；切换账号时隔离并清理旧会话 |
| 课表、成绩、考试、学业、二课、体测 | 学校系统 | 设备本地缓存和展示状态 | 迁移期兼容服务可能仍存在，是否启用由生产开关决定 |

用户登记的跨设备教务配置保存在服务端 `academic_account_configs`，仅含 App 用户归属、教务类型、学号、状态和版本，不包含学校密码、Cookie 或会话。管理员用户管理、候选人及成员摘要可以展示有效登记学号并据此搜索，优先显示已有可信身份学号；配置登记与可信学生身份分别展示，配置本身不授予身份权限。公开用户资料不返回该学号。管理统计按有效配置、可信身份或旧教务授权的现存用户去重，不读取设备侧密码、会话或原始教务数据。

### 用户主动导出的课表与考试存档

点击课表保存/导出或考试导出后，将课程或考试的展示字段写成公共 JSON 文件；不包含学校密码、Cookie、Token、个人原始 HTML 或设备密钥。Android 10 及以上位置为 `Download/沈理校园/课表存档/`、`Download/沈理校园/考试存档/`，旧版本由系统文件选择器选择位置。保存时的提示显示实际位置；自动读取教务课表不会自动导出。分享使用应用临时目录内的同内容副本，仅在用户点击分享后交给其选择的应用。公共文件由用户管理，App 内删除、退出账号或卸载不会保证删除公共副本。

### User-authorized Derived Snapshot

部分功能允许用户明确授权上传经过限制的结构化摘要，例如二课快照，用于校园 Agent 或服务端分析。它不是个人教务原始数据的替代存储。

- 只接受约定的结构化字段：总学分、缺失分类、年度统计、最多 20 条近期活动摘要等。
- 服务端拒绝 `password`、`cookie`、`token`、`session`、`credential`、原始 `html` 和设备密钥等敏感字段。
- 客户端提供的哈希不作为服务端身份或来源证明。
- 用户可以通过对应 API 删除快照；删除后下游校园 Agent 不再读取该快照。

| 个人教务访问 | 迁移期可能存在兼容路径 | 新版目标路径 | 学校系统；不应经由公共 AI/MCP |

| 显式开启的社区只读工具 | 正常普通水帖的 ID、标题、正文、分类、版本、创建时间；正常评论的 ID、正文、线程定位、内置表情 ID；内置表情标签 | 沿现有 AI 结果展示 | 沿配置的 AI Provider 发送工具结果；不预载作者、联系方式列、私信、图片或上传地址。正文中的自填个人信息仍可能外发，列白名单不等于内容脱敏 |

## 留存与删除

AstrBot 集成与内置 Go AI 只读工具分别控制。集成接口每次查当前授权/身份，发帖与撤权串行争用用户行锁；教务换绑/解绑、注销、撤销协议立即撤销集成并清空待发布草稿。已完成或拒绝的草稿立即清空正文，保留幂等摘要和结果；过期草稿由6小时清理周期清空，期限见留存台账。普通来源删除或改写后，待发布草稿不再返回旧正文/执行，要求重新生成；已发给用户部署的 AstrBot、历史记忆和外部模型的数据不能本地逆向撤回。本实现未连接真实用户 QQ 或外部付费模型，正式启用需固定版本联调、资格覆盖和隐私发布复核。

社区读取新增能力默认关闭。工具结果进入现有 `ai_tool_calls` 审计，可能包含截断正文；会话删除沿现有清理流程删除所属 Run 与工具审计。来源隐藏或删除后，新增工具的新读取和幂等缓存重放会重新检查；已存在的历史审计、回答、已装入运行任务的消息以及外部 Provider 已收取的数据不会因此自动删除或逆向撤回。来源删除传播、运行中授权代次复核与专门留存治理尚待后续阶段实现，不能把当前只读增量作为生产开放验收。留存现状见对应台账，不把工具调用过期字段当成自动物理删除机制。

具体留存期限以 [`retention-and-backup-inventory.md`](./retention-and-backup-inventory.md) 和产品/法律要求为准。账号注销、绑定解除、快照删除和推送关闭必须分别执行对应清理，不以删除客户端缓存替代服务端清理，也不以服务端清理替代设备侧凭据清理。
