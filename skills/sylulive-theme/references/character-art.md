# 人物主题的找图与制作

## 从附件追到能核对的画面

1. 逐张查看原尺寸附件，圈出角色之外也能辨认镜头的细节，例如持麦的手、发夹朝向、伙伴的耳形、背后的灯串。手机截图先在本地裁出插画，排除账号与帖子界面。
2. 先搜完整构图。已有公开图址时可用按图检索；只有本地附件且没有外传授权时，用图中文字、官方原文名、造型、道具组合检索片方图集或原作者页面，在本地并排比对。查到相似图时，再用发饰、手势或印字等局部换入口搜索。遇到镜像转载，在本地翻转搜索副本复核配饰方向，入包保留原作方向。官方预告可以记录镜头时间。
3. 回到发布页，记录署名、日期、图注、可取得的清晰版本。用几个位置相隔较远的细节判断是否同一幅构图；分别标出「同一画面的裁切」「同角色、不同镜头」「仅风格相近」「未核实」。转载数量、搜索排序和最早索引时间都不能确认首发。把参考用途、可否入包另列。
4. 再搜适合其他场景的镜头。查看首页、校园页头等槽位的真实形状，比较各候选里人物的占比、动作和留白。每张主场景图都要有可辨认的主题人物；配色、风景、道具和用户帖子不能代替这一项。

## 从角色原图制作一张样片

1. 按「人物 × 形态」整理基准图。用户明确指定的造型优先。需要画新镜头时，为每人选面部清晰的正面或近正面和另一角度，跟角色设定交叉核对。群像另记站位、视线、道具归属。只有原画裁切任务、且原画达到 SKILL.md「画质门槛」的尺寸和比例时，才直接保留原画人物。
2. 只做一个实际页头大小的样片。为新镜头把对应角色的基准图交给图像编辑工具，描述动作、站位、裁切和可改区域。后续各页始终回到同一组原图；连续拿生成图做下一张的唯一依据会累积误差。换服装或形态先换对应基准。
3. 把原图、样片的同尺度脸部局部、手机实际页头并排看。先核对脸型、眼形瞳色、发际与刘海、两侧和后发、局部挑染、标志性配饰；再看手是否握住正确道具、服装遮挡、边缘裁切。按人写出观察到的偏差。手机上人物过小或动作被裁断，也要换构图。优先局部修复，保住已经对上的脸和手；同一处反复失真，改用可用的原画人物，只延展外围。合格后再派生其他页面。
4. 交付时给出人物基准的来源、实际使用的原图或生成方式、虚拟机中的人物场景。机械校验交给主题测试，人物是否传神交给并排画面说明。

每张场景的最小记录为「槽位｜人物与形态｜发布页或用户原图｜匹配依据｜画面动作｜采用方式及实拍结果」。未确认的角色特写单列，先完成身份明确的场景。

**《超かぐや姫！》实查示例。** 辉夜拥抱伙伴的附件可与片方直前预告剧照对上。额前饰物的方向、两张脸的接触位置和身后灯串一致，附件取景更紧。这张附件只有 600×375，作为校园页头的角色参考，按 SKILL.md 的规格重新生成胸部以上、头顶留空的横幅，不直接裁切入包。片方两批剧照另有现实彩叶的正面和趴桌镜头，可看清青绿色瞳孔、两侧长发和束起的后发；这组材料用于现实形态。虚拟演出的双人主题另用舞台造型核对彩叶与辉夜的站位、键盘和麦克风。[片方直前预告与剧照](https://prtimes.jp/main/html/rd/p/000000090.000032680.html) · [片方主预告与剧照](https://prtimes.jp/main/html/rd/p/000000085.000032680.html) · [官方角色设定](https://www.cho-kaguyahime.com/)
