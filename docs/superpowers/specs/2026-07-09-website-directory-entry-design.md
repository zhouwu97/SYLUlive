# 网站大全入口设计

## 背景

工具箱页的“常用工具”区域目前包含“二课分查询”“体测成绩”“考试日程”三个工具卡片。用户希望新增一个同款小工具入口，用来承载后续常用网站集合，例如学校官网、教务相关网站、比赛平台等。

## 范围

- 在 `ToolboxScreen` 的“常用工具”网格中新增一个卡片。
- 卡片标题为“网站大全”。
- 卡片副标题为“用得到的网站”。
- 视觉风格沿用现有 `_buildToolCard`，保持同样的卡片尺寸、圆角、阴影、玻璃背景和响应式列数。
- 点击入口后进入独立“网站大全”页面，展示可上下滚动的网站列表。

## 交互设计

常用工具区域显示四个入口：

1. 二课分查询
2. 体测成绩
3. 考试日程
4. 网站大全

“网站大全”使用蓝色系图标，建议图标为 `Icons.public` 或 `Icons.travel_explore_outlined`，表达网页导航含义。点击卡片后通过 `Navigator.push` 进入独立网站大全页面，页面内以纵向卡片列表展示网站项。单个网站项包含标题、副标题、URL、图标和颜色。

## 数据与扩展

网站列表采用前端静态数据即可，不需要新增后端接口。后续添加真实网站时，只需要补充静态列表项：

- `title`：网站名称。
- `subtitle`：一句短说明。
- `url`：跳转地址。
- `icon`：Material 图标。
- `color`：卡片主色。

点击网站项通过 `url_launcher` 打开外部网页。

## 错误处理

- `canLaunchUrl` 或 `launchUrl` 失败时提示“无法打开链接”。
- 跳转前后不影响当前工具箱页面状态。

## 验证

- 运行 Flutter 静态分析，确认新增代码无分析错误。
- 重点检查工具箱页在两列和单列布局下文字不溢出。
- 确认“网站大全”副标题显示为“用得到的网站”。
- 确认点击“网站大全”后进入独立页面，并能看到真实网站列表。
