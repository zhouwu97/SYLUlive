    V4 改了什么

    评论
    • 接上服务端已有但前端没用：POST/DELETE /api/replies/:id/like（like_count 已返回）、?sort=hot|latest、GET /api/posts/:id/replies/:id/children
    • 回复不再平铺：一级评论 + 折叠子层，缩进带导轨线，最多两层后走「展开更多」
    • 「回复」改为就地编辑器，不弹 modal，保留上下文
    • 表情与图片尺寸固定，操作按钮不再和表情挤同一行
    帖子详情
    • 动作分两层：点赞 / 收藏 / 评论 / 分享 留在主条；举报 · 编辑 · 收藏首图为表情 · 删除 收进「···」，删除走 danger 语义 + 二次确认
    • 关注按钮紧跟作者块，不再被推到面板最右
    • 正文 16px / 1.85，行宽 ≤62ch；长截图按比例限高并居中，不再裁切或留大片空白
    Feed 卡片
    • 去掉 slice(0,50) / slice(0,220) 硬截断，改 CSS 两行 clamp，中文不断句
    • 图片按数量与比例自适应；4 张以上最后一张叠 +N
    • 分享统一成图标；分区 chip 上卡片，扫读时能分辨内容类型
    • 列表用分隔线，不再每条一个阴影卡
    发帖框
    • 默认折叠成一条 44px 触发栏，就地展开，不必先开 modal
    • 大块虚线拖放区改成「拖入时才出现」+ 一个追加缩略图位
    • 字数计数、发布按钮在未有效前 disabled、提交中有 loading 态
    点赞 / 收藏
    • 命中区 ≥44px（现在 .post-action 约 30px，低于无障碍线）
    • 选中态同时改图标 outline→filled，不只靠颜色
    • 乐观更新 + 失败回滚；激活 180ms 缩放，prefers-reduced-motion 下只留颜色
    首页
    • 今日卡片保留为唯一强表达元素，去掉渐变堆砌，周次与节次做层级
    • 常用功能改图标行，不再是 6 个等大卡片
    • 去掉链接文案里的「→」；分区列表去掉 01/02/03 编号（分区不是序列）
    课表（参考 App 平板 + 桌面）
    • 结构照搬客户端 course_schedule_screen.dart：第 N 周大标题 + 学期日期区间 + 时间轴固定在左、7 列随周次切换
    • 时间轴补上真实钟点：12 节 · 45 分钟 + 10 分钟课间，Web 端原来只有「第 1-2 节」
    • 课程色沿用 App 的 getCourseColorIndex 哈希（同一门课同色），色块改为浅底 + 深色字，白字压 45% 底色在 Web 上过不了对比度
    • 补上 Web 缺失的三种态：单双周占位（前期/后期）、节次重叠冲突块、本周无课
    • 点课程块 → 右侧详情抽屉，字段与 App CourseDetailSheet 对齐：教师/地点/周次/来源 + 调整课程安排 + 课程评价
    • 右侧补上 App 桌面态的今日概览（_buildTodayOverview，320px）：当天课程按起始节次排序，时间 chip + 第 N-M 节 + 教室/教师，点条目打开同一个详情抽屉；无课、未连接、读取中各有对应状态。<1320px 折到表格上方两列（面板 320px + 表格 7 列至少需要 ~700px 才不挤），与 App「平板只有网格、桌面才出面板」一致
    • 保留 Web 已有能力：刷新课表、导出 JSON、添加课程、显示周末、节高密度、回到本周
    • 示例数据：课程表是按 App 字段构造的一周样例（冲突、单周体育课、后期实习都是刻意安排的），不是你本人的真实课表
    对比度（浏览器实测，非估算）
    • 三级文字阶梯在米白底上不成立：页面底 #f7f4ec 亮度 .905，4.5:1 要求文字亮度 ≤ .156，而原 --text-2 已经是 .153 —— 任何比它更浅的档位必然不达标
    • 改法：阶梯整体下移一档，--text-2 #5f716b → #4a5b55，--text-3 #8b9a94 → #5f716b（4.7:1，正好落在地板上，注释已写明不得再调淡）；深色同理 #7b8c86 → #85968f
    • 主按钮白字压 --brand 只有 3.5:1（深色下 1.92:1）：浅色改用 --brand-strong，深色改用亮青底 + 深色字
    • --danger 作正文色 4.1:1：新增派生值 --danger-ink（danger 与 text 混合，随主题自适应），删除/超限计数/点赞态/警示前缀统一改用
    • 精华 chip、未读角标、冲突提示条同理，全部由既有 token 混合得到，没有新增色值
    • 色块标题保留 App 取色，但底色浅、文字深：本周出现的 4 组课程色 + 冲突/前期后期占位态，块内文字最低 5.8:1
    • 这一组是 token 级结论，落地时同样适用于 web/src/styles.css（那里 --text-3 也大量用在评论时间、楼层计数等正文小字上）
    数据与状态
    • 帖子、评论、头像、配图全部是 sylulive.online 的真实内容快照（2026-09-29）
    • 设计态说明：真实数据里 parent_reply_id 全为 null，帖 634 的嵌套回复与「1 条回复」计数是为了演示层级而构造的
    • 加载 / 空 / 错误 / 重试 / 未登录状态可在「预览：加载态」按钮与深色开关检查
