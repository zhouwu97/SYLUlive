- 日期：2026-10-26；基准：`ce8dfec40bcce0481e6c016efd82840f496f471f`。
- 目标：修复评论线程、编辑资料及同类入口的玻璃遗漏，检查深色／简洁模式后推送客户端改动。
- 风险：本轮表面替换为 R1；一并交付的既有回复通知／账号隔离修复按 R2 留存验收与回退记录。
- 环境：Windows、Flutter debug、ADB Pixel 8 / API 37.1。逐文件清单见[166 个页面源码背景入口](2026-10-26-page-glass-inventory.md)。

## Changed（修改）

### 直接反馈的两个入口

- 评论详情线程的实色根容器替换为 AppCardSurface，相关回复分界带接入 AppCardDivider。输入栏采用 embedded 模式沿用弹层材质，避免第二层实色底板、描边或重复不透明度。
- 评论摘要内的普通实色底板在玻璃模式透明，保留目标回复高亮、图片／表情、点赞、回复、举报、删除及账号权限行为。楼中楼列表在玻璃模式关闭逐条重绘边界。
- 编辑资料弹窗保留透明 Dialog 外壳，内部根表面使用 AppCardSurface；两个入口行不重复绘制实色底板。保留昵称、性别、保存、失败提示、键盘和主页封面操作。
- 普通帖子顶栏在自定义背景下透明，并关闭滚动染色和阴影，消除顶栏白块及背景截断。

### 全面扫描后的同类遗漏

- 逐文件检查 `client/lib/screens` 下 166 个 Dart 文件，并检查共享 widgets 与 Feature 页面外壳；按页面背景、内容表面、弹层、菜单、普通分隔线和专用画布分类处理。
- 统一普通确认／错误／权限弹窗到 AppAlertDialog，普通菜单到 AppPopupMenuButton，装饰 Divider 到 AppCardDivider。菜单补齐 initialValue 转发，保留选择定位、禁用条目、回调和键盘行为。
- 补齐成绩筛选／GPA 说明／学期选择、校历、课程预览／课程详情／调课、集市筛选、竞赛说明／管理、评分输入、AI 来源／模型选择／反馈、图片来源和举报等自绘弹层根表面。
- 新增 showAppModalBottomSheet，覆盖 36 处依赖原生 Material 底色的默认或显式底色弹层。与卡片复用最终底色计算和 FrostedGlass，保留原生路由、拖动手柄、形状、安全区、焦点、键盘避让及返回值；仅在玻璃模式裁剪模糊并应用一次透明度。已有自绘透明弹层继续使用自己的 AppCardSurface。
- 补齐发布类型／底部操作栏、回复提醒／列表、关注空态、AI 状态提示等表面；私信与评论共用输入栏在独立显示时接入玻璃，内嵌时不叠加材质。
- 表情管理共享页面外壳接入 AppPageBackground；深色 AI 状态提示和课表导入成功提示使用深色表面及可读文字。AppBar 系统状态栏样式按主题明暗配置，修复简洁浅色下默认白字对比不足。

本次同时包含此前本地已完成的成绩卡片、学期间距、回复通知已读同步及桌面组件修复，细节和原生测试见[前一轮记录](2026-10-26-reply-read-grade-glass-widget-divider.md)与[组件主题更新记录](2026-10-26-widget-theme-snapshot-fix.md)。

## Preserved（保留）

- 官网、Web 及无关资源改动保留本地，不纳入此次客户端推送。
- 不修改页面请求、鉴权、授权、删除／保存等业务回调。普通线条隐藏时保留原来的布局间距；步骤连接线、输入边框、选中状态保留语义。
- 地图、图片／试卷／网页等专用画布、二维码、图片占位、业务徽标和个人主页封面保留相应背景策略，避免把内容画布当作普通卡片替换。
- 简洁模式隐藏全局自定义壁纸且保留已选图片，玻璃表面使用不透明主题底色；深色使用对应表面与文字色。毛玻璃关闭时回退原有组件样式。
- 复验后恢复浅色、自定义背景、标准 100% 字号和开启毛玻璃；不修改昵称、性别、封面，不发送评论或私信，不清理用户数据。
