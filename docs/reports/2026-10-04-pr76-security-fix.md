## 修复与兼容边界

1. 告警涉及的 20 个 Go 文件按 `strconv.IntSize` 解析将转成 `uint` 的 ID。64 位合法 ID 范围保留，32 位溢出拒绝，不再截断到其他资源 ID；分页游标的时间戳继续使用 64 位。
2. 验证码和反馈邮件拒绝地址中的控制字符，使用标准邮件地址序列化。动态主题采用 RFC 2047，正文采用 RFC 2045 Base64 并按 76 字符折行；验证码 HTML 先转义。验证码收件地址仅用于已校验的 SMTP 信封，To 使用固定的空收件组，避免客户端输入进入邮件头。保留中文、emoji、正文和截图 CID 引用，防止动态内容引入邮件头或 MIME 边界。
3. 研究生挑战状态只允许 ASP.NET 会话前缀，登录请求从固定学校来源创建，再设置合法路径，继续禁止登录 POST 自动重定向。保留学校会话路径的字面括号，避免 URL 编码改变会话行为。
4. 公开图片回补使用 `os.OpenRoot` 的目录句柄打开文件，阻止符号链接及路径竞态越过上传目录，并限制读取量不超过表情总配额。
5. 竞赛排序追踪在分配处限制最多 50 条，不依赖上游分页归一化。
6. 兼容课表接口的会话失效响应使用固定公开提示，保留错误码，避免异常文本泄露内部信息。
