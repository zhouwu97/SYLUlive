# 本机主题包

入口：界面设置 → 主题 → 导入主题／本机主题。文件后缀为 `.sltheme`，ZIP 格式及基础字段遵循[格式契约](../../../../docs/design/theme-pack-contract.md)。本批实现选择文件、校验、预览、保存、按组应用、跨重启恢复、单份上一个外观、恢复手动外观，以及分享已安装包。

应用分组为配色、圆角、壁纸、卡片材质、导航栏。未勾选的组保留当前值；深浅配色跟随原有明暗设置，文字大小独立保存。手动选择壁纸只替换壁纸组，手动调整卡片材质只改当前明暗变体的对应值，手动调整导航效果保留主题图标。恢复上一个外观会交换两份完整快照，恢复手动外观使用现有手动偏好。

ZIP／JSON 在工作 isolate 读取，实际解压输出有上限，读取条目执行 ZIP 原生 CRC 校验，不另加资源哈希。图片先查尺寸再完整解码，只允许静态 PNG／JPEG／WebP。字体本批校验 SFNT 头部与表边界并保存，运行时加载在 P1.5 实现。本机包忽略 `source`，对比度不足显示提醒并允许应用。分享使用系统分享面板，导出的包不包含个人资料。

主题目录为应用 documents 下的 `themes/`。安装先写 `.staging/`，完成后 rename 到 `installed/<id>/<version>/`，索引只列每个 ID 的最新版本。所有写入复用 ThemeProvider 原有外观队列。当前外观、上一个外观和手动壁纸偏好引用的文件都受保护；删除主题只移出列表，失去全部引用后清理旧版本。旧手动壁纸复制进 `user/` 后更新偏好，原应用受管目录中的旧文件随之清理，外部相册和文件保留。

布局与装饰只解析、保存，不参与本批应用。按已确认的删减口径保留三个页头的 standard／compact／immersive 模板、每个页头最多 5 张贴纸、描边与阴影，以及亮度／对比度／饱和度。忽略 density、cardStyle.radius 和 sharpen。壁纸调色在渲染时使用颜色矩阵。字体、小部件与启动图标应用属于 P1.5，页头与装饰渲染属于 P1.6；全局限时试用、系统文件关联和导出当前混搭外观仍待后续批次。主题商城、在线上传和网页应用不在本批范围。

验证入口：`flutter test test/theme_pack --concurrency 1`。已有表情包导入器复用同一条有输出上限的 ZIP 条目读取函数，修改时同时运行 `test/features/emoji/emoji_pack_importer_security_test.dart` 和 `emoji_pack_import_flow_test.dart`。真实渲染截图写入忽略提交的 `client/build/theme-p1-qa/`，不提交 Golden 或二进制夹具。
