# SYLU Notes

A limited text subset of [LXGW WenKai](https://github.com/lxgw/LxgwWenKai), distributed under the accompanying SIL OFL 1.1. The modified font family is renamed to SYLU Notes. Only short decorative notes use this font; ordinary content uses existing system fonts. Served locally without a runtime CDN.
