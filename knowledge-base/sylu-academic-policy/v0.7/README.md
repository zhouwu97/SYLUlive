# SYLUlive 官方学业与学生资助政策知识库 v0.7

v0.7 是在 v0.6 基础上的增量补充版本，新增校级奖学金、国家奖助学金、家庭经济困难认定、校助学金、孤儿资助、勤工助学和国家助学贷款材料。

本版本必须与 v0.6 已发布文档共同导入；不得撤销 v0.6 的学籍、补考与重修材料。

## 导入顺序

1. 保留已发布的 v0.6 文档；
2. 导入 `SYLUlive_AI学生资助政策增量导入包_v0.7.jsonl`；
3. 对新增文档完成 inspect、reindex、publish；
4. 抽测“奖学金怎么评”“国家励志奖学金和国家奖学金能同时拿吗”“孤儿有哪些资助”“勤工助学一小时多少钱”等问题。

来源为用户提供的学校网页政策全文转录。导入后仍应在学生处或学院当期通知发布时核验名额、时间和可能的修订。
