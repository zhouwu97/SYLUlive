# Beta-0 内测发布说明与验收清单

版本定位：**沈理校园 内测版 · 学业总览 Beta**

## 发布范围

- 成绩中心：学期成绩、学业总览、GPA、课程状态、学分汇总、刷新、数据来源与抓取时间。
- 毕业预警：仅保留验证中说明页，不生成风险、缺口、模块或毕业资格结论。
- AI 助手：保留普通对话、公开竞赛搜索和经过授权的个人数据工具。
- 竞赛中心：保留目录、筛选、搜索和用户自主加入计划；隐藏推荐等级与个性化适配。

以下能力由 `BetaReleasePolicy` 统一冻结：毕业结论、AI 毕业助手、个性化竞赛适配、AI 组队、获奖档案、政策收益和客户端探针。

## 自动发布门禁

在仓库根目录执行：

```powershell
cd client
powershell -ExecutionPolicy Bypass -File scripts/verify_beta_release.ps1
flutter test
powershell -ExecutionPolicy Bypass -File scripts/build_beta_release.ps1
```

门禁会检查 Beta 版本格式、生产 HTTPS API、冻结功能开关、隐私文案，以及真实探针输出未被 Git 跟踪。构建脚本继续校验 APK 版本、签名并生成 SHA-256 与发布清单。
