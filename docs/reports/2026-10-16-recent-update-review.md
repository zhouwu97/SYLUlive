### 业务验收

1. 专用测试账号 → 触发账号/IP 内存锁并注入限流表查询故障 → 正确和错误密码均应在用户查询与 bcrypt 前返回 429、不创建会话 → SQLite 与 PostgreSQL 验证；数据库恢复可读后遵守共享状态。
2. 专用测试账号与持久化别名 → 邮箱重置 → 新密码可从邮箱、QQ、历史别名登录；旧凭据拒绝、其他账号/IP 保护保留 → 隔离 PostgreSQL 验证。
3. 页面 A 会话 → 401 刷新／重放／延迟读响应体期间切至 B → 不返回 A 的数据、不在 B 下继续上传 → 单元与 Chromium 夹具验证。
4. 社区发布 → 图片上传中关闭弹窗 → 迟到结果不继续调用帖子发布 → Chromium 验证。
5. 收藏原有内容 → 单项上传失败 → 保留条目并展示重试；重试成功后提示清除 → 360×800、1.3×、浅色／深色实际页面渲染与交互验证。
