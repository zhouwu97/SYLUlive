# 沈理校园客户端

这是 SYLUlive 的 Flutter 客户端，负责校园 App 的界面、账号交互、社区功能，以及逐步迁移到设备侧的个人教务访问。

## 客户端边界

- App 账号、社区、竞赛、通知和反馈通过 Go 服务端访问。
- 个人教务访问优先由客户端直接连接学校系统，并通过设备安全存储保存本地会话和缓存。
- 学校密码、Cookie、个人教务 HTML 和原始会话不得写入服务端日志、远程 AI、MCP 或普通业务接口。
- 迁移期旧 `/api/edu/*` 能力可能返回 `410`；客户端应遵循能力探测结果，不应反复调用已退役接口。
- 手机已连接教务而服务端账号配置缺失时，完整查询确认缺失后自动通过 `/api/academic-account-configs` 补登记学号与教务类型，包括曾同步成功后记录缺失的情况。已有云端解绑、不同学号、版本冲突或账号切换时不自动覆盖；登记不授予可信学生身份权限。

## 课表与考试存档

- “调整课程安排”先选择原周次，再选择目标起始周、星期和节次；整段提前或延后时保持单双周和离散周次的间隔，目标周次不能超出本学期。
- 调课确认页同时展示原安排和新安排。目标位置已有同一课程且时间完全相同的教务原安排时，可勾选合并；不同课程、部分节次重叠和已有本地调整继续提示冲突。恢复原安排会撤销这条调课及其合并效果，不修改教务原始快照。
- 本机课表刷新传递学校真实学期 ID；本科兼容学期码保留 `3/12`，研究生使用学校返回的 ID。
- 用户点击课表“保存当前课表为新存档”时，同时保存 App 内存档和公共 JSON 副本；已有 App 内存档可点击导出补写公共副本。
- Android 10 及以上通过 MediaStore 保存到 `Download/沈理校园/课表存档/` 或 `Download/沈理校园/考试存档/`；Android 9 及以下由系统文件选择器选择保存位置。
- 公共文件导出失败会明确提示重试，已保存的 App 内课表仍保留。公共副本由用户在文件管理器删除，卸载、退出账号或删除 App 内存档不会自动清理它。
- 考试日程页面维护本地考试安排，支持手动添加和 JSON 导入/导出；该页当前不提供从学校获取考试安排的入口。

## 互动消息

- 在“我的 → 收到的赞”查看点赞者、点赞时间与原帖；评论点赞可定位到对应评论。列表包含历史有效点赞，支持刷新、分页和失败重试。
- 回复提醒使用首页未读入口与系统通知。成功定位目标回复后只消费该回复的通知；已读状态同步到 Android，清理对应系统提醒并拦截延迟推送。
- 新回复通知使用独立高优先级渠道；关闭系统权限或单独关闭该渠道时不会绕过用户设置。

## 我的页面与平板导航

“我的”沿用信息流的分栏边界：扣除首页侧栏后，可用宽度达到 840 时左栏保留 380 宽的个人中心，二级页面及其后续跳转在右栏打开，返回逐层退出。左侧切换功能会替换右侧导航栈，并遵守详情页的离开限制。窗口收窄后保留已打开的详情、输入与滚动状态；从窄屏新进入二级页面仍使用整页导航。账号、会话或角色变化会清空右侧旧页面。

分栏中的二级页、帖子详情与个人主页通过 `SharedPageBackground` 共用外壳的整张壁纸，不重新绘制局部壁纸；个人主页原有的用户封面继续显示，帖子和商品卡片的左右边缘与上方标签栏对齐。独立打开的页面继续使用原有背景和留白。

集市与个人主页复用 `AdaptiveDetailLayout`：集市在剩余宽度达到 840 时保留左侧商品列表，商品、作者主页及后续帖子在右侧逐层打开。单独打开的宽屏个人主页在查看内容时分栏；已在信息流或个人中心详情栏内的主页沿用当前区域，避免再打开整屏或第三栏。收窄后保留详情、回复草稿和列表位置，返回先回到来源主页，再退出详情。会话或角色变化会清空旧详情，集市搜索的晚到结果也不能回填新会话。

## 表情包

表情功能入口为输入面板的“表情管理 → 添加”：可多选相册图片、导入图片 ZIP / `.sylupack`，预览改名后安装到当前账号的本机目录。本机导入无需网络；新投稿、创作者与社区目录需要配套 Go 服务端。资源与兼容边界见 [Emoji 资源契约](../docs/design/emoji-resource-contract.md)。

制作外部文件时，普通图片 ZIP 以文件名作为逐张对应文字；需要明确文字和资源关系时，使用根目录 `manifest.json` 的 `assets[].path` / `name`。缩略图由系统生成，不要额外打包。完整字段、目录示例和限制见 [ZIP 与 sylupack 制作格式](../docs/design/emoji-resource-contract.md#8-zip-与-sylupack-制作格式)。

新版提供免费“表情商城”和“创作中心”直达入口。普通用户可自由导入自用并整理仅本机个人标签；公开投稿需先申请创作者权限，每包/每次更新单独审核。创作页支持账号隔离的自动保存草稿、逐张文字、公开标签、封面/面板图标选择和上架效果预览，失败或取消上传保留草稿。网格使用系统生成的静态缩略图，点击才展示完整图片/动图。管理员在“表情创作者审核”开通、驳回和暂停权限，自己的申请及作品均需其他管理员处理。流程与迁移边界见 [实施方案](../docs/design/emoji-creator-store-plan.md)。

帖子、评论及图片查看器会自动播放 GIF 原图；选择面板使用静态预览。官方「明风 OvO」匹配原始动图内容哈希时使用对应的内置预览，其他内容继续使用本机派生图。自动播放原图可能比静态图消耗更多流量。

管理页支持按包名、个人标签和逐张对应文字查找；输入面板中的已安装包支持按对应文字筛选，切号清空筛选状态。商城“返回使用”会回到面板并选中安装包。本机包异步加载后的标签切换直接定位目标页，避免旧滚动边界让分页动画停在“最近使用”。

Windows 可从仓库根运行 `./scripts/verify-emoji-chain.ps1`，联调真实 Flutter 页面和 Go API。脚本只启动随机 loopback TLS 端口、临时 SQLite 与上传目录，注入隔离 API 地址；覆盖导入、申请、审核、商城、安装返回、筛选、评论上传和下架保留，结束回收临时服务。需要本机 Go、Flutter 和已安装依赖；运行时串行执行 Flutter 检查，避免共享原生 DLL 构建目录冲突。该显式联调在普通 `flutter test` 中跳过，不替代 PostgreSQL、代理和手机验收。

## 二课成绩更新

- 二课页打开时先显示当前账号的加密成绩缓存，再用已保存凭据后台更新；下拉、顶部“更新”和菜单“更新二课数据”复用同一流程，刷新期间保留已有成绩。
- 首次验证可选择“在本机安全保存密码”，成功认证后通过 `DeviceCredentialStore` 写入系统安全存储，与校园 Agent、个人数据中心的更新入口复用。取消保存只在当前页面会话保留密码。Web 的安全存储不持久化密码。
- 学校返回的通用登录错误、HTTP 401、网络超时和页面解析失败不能单独证明密码错误。二课模糊错误先核实受保护页面，再最多恢复登录一次；只有 CAS 明确拒绝账号或密码才要求修改凭据。
- 毕业要求、学年要求和活动记录独立获取，部分失败保留原有对应数据；学年活动与全部活动分别缓存。已有学年缓存支持离线查看。
- 部分刷新保留原快照时间并持久标记不完整；保险箱和个人 AI 将其作为需同步数据。混合新旧值的摘要暂不上传，完整刷新后恢复既有授权上传流程，不改变服务端 v2 契约。
- 二课页面、个人数据中心及设备任务的更新与摘要上传绑定 App 账号、教务来源和会话代次；上传/删除在请求发送前复核发起会话。同一账号重新登录也会取消旧流程。个人数据中心更新与清除互斥，切号后需重新打开。
- “修改登录密码”和“清除已保存密码”在二课页菜单；“清除本地缓存”仅清成绩，个人数据中心清除本机个人数据会同时清理保存的二课密码。历史 SharedPreferences 明文密码不迁移，只清理。

## 我的 AI 机器人

连接区显示由服务端核验的后台运行状态、最近浏览、下次计划及 bot 作者的真实成功发言；约30秒独立刷新，失败降为尚未核验并保留资料／权限草稿，切号与晚到响应不能回填。执行端离线或无本人授权不显示正在运行；旧服务未提供协议时明确不可核验。创建者、普通账号的任务都由常驻 AstrBot 承载，App 不需要驻留，开关及授权方式见插件说明。

该页沿用设置页背景入口、共享卡片材质和现有青绿品牌。毛玻璃与卡片透明度由外观设置统一控制；关闭毛玻璃停止模糊并保留手动不透明度，简洁背景恢复实色卡片。维护时复用 `AppCard` / `AppCardSurface`，内部信息行、输入与状态不要再叠一层模糊或不透明底面。状态图标和文字必须同时保留，无障碍与真实渲染验证按开发与交付规范执行。

设置 → 我的 AI 机器人提供新建（默认暂停）、名字与公开头像编辑、社区权限及言论规则、启用／暂停和原生 AstrBot 连接授权。资料和主要操作前置，社区参与与发言规则分组查看，记忆隐私以摘要及可展开详情呈现。仅成功读取并确认没有机器人时展示新建；加载、无法读取和旧服务单独显示状态，不伪造创建结果。

社区权限采用公开浏览总开关、评论／表情独立能力选择及板块多选清单；发言节奏支持每日额度分段选择、间隔快捷选择和自定义。预设只修改草稿，保存前显示待保存。失效板块提供明确移除，处理前不能保存／启用，紧急暂停仍可使用；组内控件只用平面选中态，不叠加毛玻璃。

复用 `/api/connected-apps/bot`，两端共用服务端规则；请求绑定当前账号会话代次，切号清空旧状态。账号启用、服务端开放、专用评论授权分别显示，不声称后台已运行。头像复用相册、方形裁剪及现有上传，保存失败保留草稿。记忆与模型仍在本机 AstrBot 管理，App不读取私聊库；群仅短时上下文，创建者私聊与公开阅读分开保存。接口与规则见 [服务端 API](../server/API.md) 和 [插件说明](../astrbot_plugin_sylulive/README.md#社区机器人账号管理)。

## 开发环境

- Flutter 3.x
- Dart（版本约束以 `pubspec.yaml` 为准）
- Android Studio 或 VS Code
- Android SDK；iOS 构建需要 macOS 与 Xcode

## 运行

```bash
flutter pub get
flutter run
```

液态玻璃的 Android 视觉验收使用默认 GPU 渲染。Android Studio 的运行参数应与命令行保持一致，不额外开启 `--enable-software-rendering`；软件渲染截图不能代表 GPU 折射材质的实际效果。

本地联调时，请把客户端 API 地址指向开发机可访问的 Go 服务。不要把真实学校账号、密码或 Cookie 写入提交内容、测试快照和日志。

## 常用检查

```bash
flutter analyze
flutter test
```

涉及界面、动效和无障碍的改动，先检查 `lib/theme/`、相关共享组件与已有测试，具体设计按本次任务要求执行。状态、异步竞态、无障碍和真实渲染验收统一见 [开发与交付规范](../DEVELOPMENT_STANDARD.md#42-flutter-与客户端)；[功能契约与决策记录](../docs/design/README.md) 中的数据和权限边界继续适用。

自定义背景下普通卡片、弹窗和预览使用 `ThemeProvider.effectiveComponentOpacity`。卡片不透明度滑块的 0–100% 线性映射为实际底色的 75–100%，偏好保存实际不透明度。历史 75% 对应新 0%，更低的历史值使用新最低档。文字和图标沿用主题前景色。课表独立透明度与显式透明容器继续使用自己的设置；关闭毛玻璃只停止模糊，简洁背景恢复实色卡片。

卡片效果预设同时填入不透明度档位和模糊强度。关闭使用 100%／0%，高性能使用 75%／35%，高画质使用 0%／100%，自定义从 50%／65% 开始。手动调整后按完整组合匹配预设，保存重试使用当前数值。

## 原教务绑定自动同步

教务绑定保留原入口；本机学校登录成功后检查服务器身份，缺失时先对账账号配置，再以临时学校会话让服务器向固定学校入口重新核验学号。恢复本机会话、刷新课表和网络重试沿用同一补交流程，不新增学生绑定／单独认证入口。学校密码不随补交上传，服务端不保存学校会话。接口部署前置条件与验收步骤见[绑定测试说明](docs/student-identity-test.md)。
