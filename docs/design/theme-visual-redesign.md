# 主题视觉改版方案（V2）

状态：V2-1 沉浸页头、V2-2 氛围背景与识别色协调、V2-3 卡片填充／区块记号／状态插画／标题字体已实现，字段见格式契约 2.7 与 2.10 节。用海盐蓝、樱粉两套素材制作了 V2 主题包（`artifacts/theme-v2/`）并在九页明暗下渲染验收。尚未完成：主题工坊对这些新字段的编辑入口、移动网页端的氛围背景与识别色协调、课表氛围（3.7）、校园四季与纸感的素材。

相关文档：[ADR-005](adr/005-theme-package-and-store.md)、[格式契约](theme-pack-contract.md)、[制作细则](theme-creation-guide.md)、[实施计划](theme-store-plan.md)。

## 1. 现状诊断

诊断依据是 `artifacts/mingfeng-theme/campus-break/` 下"明风 · 晴蓝"主题在九个页面的明暗实拍截图，以及 `theme_presentation.dart` 的源码。

| # | 问题 | 现象 | 根因 |
| --- | --- | --- | --- |
| D1 | "沉浸"页头并不沉浸 | 首页是"横幅图卡片 + 一张单独的'沈理社区'信息卡"，上下两块拼在一起；"我"页的人物缩在一条胶囊里，和资料卡脱节 | `ThemeHeaderFrame` 的三种预设只是把装饰区放在信息卡上面或下面（一个 `Column`），图片不伸到状态栏下，文字也不叠在图上 |
| D2 | 主视觉重复、背景发脏 | 同一个角色既是全屏壁纸，又出现在页头；壁纸经过模糊和遮罩后，在卡片后面只剩一团肤色和衣服的色块 | 壁纸被当成主视觉来用；契约没有"氛围型背景"（渐变、纹理），作者只能放图 |
| D3 | 主题只上了一半色 | 集市整页仍是橙色；校园服务图标是红、橙、绿；"诚信 100%"是青色；发布按钮是深蓝圆。这些都和粉蓝主题打架 | P0 把识别色一律标成 `theme: fixed`，主题不能动它们。状态色和识别色混在一起处理，没有协调机制 |
| D4 | 所有表面长得一样 | 页面上每一块都是"半透明白卡加细边框"，分不出层级；空状态是一个巨大的空白框 | 卡片只能改描边和阴影，没有填充风格；区块标题没有任何装饰；空状态不接收主题插画 |
| D5 | 字体没有性格 | 标题和正文同一种黑体，换配色后看起来仍是原 App | 字体只能整体替换，没有"只换标题字体"的选项 |
| D6 | 暗色是亮色压暗 | 暗色首页是灰蓝色雾，人物发灰 | 暗色复用同一张图，只加了遮罩；制作细则对暗色素材的要求太弱 |
| D7 | 交互元素没被主题化 | 底栏选中项是灰色胶囊；FAB 是默认深色圆；Chip 是默认样式 | 这些组件读的是固定的中性色，或者没有暴露出样式参数 |

结论：素材本身不差（课表页反而最好看，因为它的色板、网格和角落的小星星是一个整体）。真正的问题在**引擎能力**和**构图规则**。

## 2. 设计原则

1. **一个焦点**。角色或主视觉只出现在页头 hero 里（首页、我、校园）。全局背景只负责氛围：渐变、纹理、虚化的天空或场景，不放人物全身。
2. **页头真正沉浸**。图片铺到状态栏下方；标题、分段 Tab 叠在图上；图片底部渐隐进页面底色；第一张内容卡上移，压住 hero 的底边。
3. **颜色全部贯通**。按"状态色不动、识别色协调"的规则，让分类图标、集市橙色、徽章都向主题色相靠拢；FAB、选中胶囊、Chip、开关全部跟随主题。
4. **表面分层**。页面底 → 区块 → 卡片 → 交互元素，四层分别有不同的填充和透明度。区块标题前加一个主题记号（圆点、竖条或小图标）。
5. **字体分层**。标题可以单独使用展示字体，正文保持易读的黑体。只换标题字体，就能带来大部分"风格感"，风险也最小。
6. **细节有情绪**。空状态和错误状态显示主题插画；页头贴纸；底栏图标；课表空白时段的纹理。这些都是 SukiSU 那种"好看"的来源。
7. **暗色单独设计**。暗色要有自己的 hero 图（夜景或暗调版本），不是把亮色压暗。

## 3. 引擎改造（新增能力）

以下字段全部作为 formatVersion 1 的**可选扩展**加入格式契约。主题包还没有在生产环境发布，所以可以直接扩展 v1。新增字段的包把 `minAppVersion` 设为实现它们的版本；旧包继续有效，省略这些字段时外观与现在完全一样。

### 3.1 沉浸页头重做（解决 D1，优先级最高）

把 `layout.<slot>.preset = immersive` 的含义重写为真正的叠加式页头。`standard` 和 `compact` 保持现状。

| 字段 | 范围 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `heroHeight` | 200–360 dp | 280 | 包括状态栏在内的 hero 总高度 |
| `fade` | 0–1 | 0.6 | hero 底部渐隐进页面底色（`background`）的强度 |
| `overlap` | 0–32 dp | 16 | 第一张内容卡向上压住 hero 的距离 |
| `titleTone` | `auto`、`light`、`dark` | `auto` | 叠在图上的标题、Tab、图标的颜色。`auto` 时，按 hero 图上半部分的平均亮度自动选深字或浅字，同时加一层 12% 的同色投影保证对比度 |
| `titleOnHero` | bool | true | 首页的分段 Tab 和搜索框、"我"页的头像和昵称，都叠到 hero 上 |

渲染结构：用 `Stack` 叠放 hero 图、贴纸层、渐隐层和信息层；内容列表从 `heroHeight - overlap` 开始。下拉刷新和滚动时，hero 做 0.5 倍速的视差移动，并在滚动到顶栏高度时淡出，顶栏转为实色。

三个页面的具体做法：

- **首页**：hero 承载搜索框、分段 Tab 和贴纸；原来那张"沈理社区"信息卡取消，改成 hero 左下角的一行标题。
- **我**：头像、昵称、诚信徽章叠在 hero 左下；hero 右侧留给角色；资料卡上移压住 hero 底边。
- **校园**：学期信息和周次叠在 hero 上；"校园资讯"第一张卡上移。

### 3.2 氛围背景 `backdrop`（解决 D2）

在明暗变体中新增 `backdrop`，可以替代或叠在壁纸下面使用：

```json
"backdrop": {
  "type": "gradient",                // gradient | pattern | image
  "gradient": { "stops": [["#EAF2FF", 0], ["#F7EEF8", 0.55], ["#FFF6EE", 1]], "angle": 160 },
  "pattern": { "tile": "decorations/cloud-tile.png", "opacity": 0.18, "scale": 1.0 },
  "glow": [{ "color": "#BFD6FF", "x": 0.85, "y": 0.1, "radius": 0.6 }]
}
```

- `gradient`：2–4 个色标的线性渐变。
- `pattern`：可平铺的透明 PNG（512×512），按透明度平铺，可以叠在渐变上。
- `glow`：最多 3 个径向光斑，用来做 SukiSU 那种柔光氛围。
- 页面背景的叠放顺序：渐变 → 光斑 → 纹理 →（可选）壁纸 → 遮罩。课表和集市默认只用前三层，不放人物壁纸。
- 实现上只用 `DecoratedBox` 加 `ImageShader` 平铺，不做逐像素处理。

### 3.3 识别色协调（解决 D3）

把现在的 181 处 `theme: fixed` 分成两类：

- **`theme: fixed-status`**：成功、警告、危险、未读、审核状态、金额。永远不变。
- **`theme: fixed-identity`**：分类图标、板块识别色（包括集市橙）、来源标签。可以协调。

在明暗变体中新增 `identityHarmony`（0–1，默认 0）。识别色经过 `AppIdentityColors.of(context).resolve(color)` 计算：用 HCT 色彩空间把色相朝 `primary` 旋转（最多 30° × harmony），色度乘以 (1 − 0.35 × harmony)，色调不变。也就是 Material 的 harmonize 思路，加了强度控制。

- 默认值为 0，P0 已验收的外观完全不变。
- 粉蓝类主题取 0.6–0.8，集市橙会变成偏珊瑚粉，服务图标变成同一色温的彩色，但彼此仍能区分。

### 3.4 卡片填充与区块记号（解决 D4、D7）

在 `cardStyle` 中新增 `fill`，取值为 `solid`、`glass`、`tint`：

| 取值 | 效果 |
| --- | --- |
| `solid` | 现状 |
| `glass` | 卡片底色 70% 透明度，加 12 sigma 模糊，再加 1dp 高光描边（`onPrimary` 的 20%）。只在毛玻璃开启时生效，否则回退为 `tint` |
| `tint` | 卡片底色和 `primaryContainer` 以 92:8 混合，并在上缘加一条 0.5dp 的亮色线 |

在顶层新增 `sectionMark`，取值为 `none`、`dot`、`bar`、`icon`。区块标题（"校园服务""教务""我的内容"等）前绘制一个主题色的记号；`icon` 使用 `icons/section_mark.png`（48–96px，按 template 模式着色）。

交互元素：

- 底栏选中指示改为 `primaryContainer` 胶囊，选中图标用 `onPrimaryContainer`；
- FAB 改为读 `primary` / `onPrimary`，形状随圆角档位变化（rounded 档位为大圆角方形）；
- Chip 选中态读 `primaryContainer`，未选中读 `surfaceMuted`。

### 3.5 主题插画（解决 D4、D6）

在明暗变体中新增 `illustrations`：

```json
"illustrations": { "empty": "decorations/empty.png", "error": "decorations/error.png", "loading": "decorations/loading.png" }
```

- 共享组件 `StatePlaceholder` 有对应插画时，在图标位置显示插画（最大 160dp，透明 PNG，长边 ≤ 800）。
- `loading` 用于首屏加载的骨架屏上方，只显示静态图，不做动画。

### 3.6 标题字体（解决 D5）

把 `font` 扩展为：

```json
"font": { "title": { "name": "...", "regular": "fonts/title.ttf", "license": "OFL-1.1" },
          "body":  { "name": "...", "regular": "...", "bold": "..." } }
```

- 原来的写法视为 `body`。
- `title` 只作用于 `TextTheme` 的 display、headline、title 三组，以及页头标题和区块标题。
- 标题字体可以只覆盖常用字子集（GB2312 一级 3755 字），缺字时回退到正文字体。服务端对 `title` 的覆盖率要求降为 95%。

### 3.7 课表氛围

明暗变体新增 `schedule.cardStyle`，取值为 `soft`（现状）、`solid`、`outline`；`schedule.todayMark` 可选一张贴纸（例如小星星），画在今天的列头。课表页是当前最好看的页面，只补这两项。

## 5. 官方主题美术方向

每套主题都要包含：亮色和暗色两张 hero、氛围背景配置、一张纹理（可选）、2–3 张贴纸、一组空状态与错误插画、5 个底栏图标、1 个区块记号、内置桌面图标。字体只用 OFL 等可再分发许可的字体。

| 主题 | 概念 | Hero（亮 / 暗） | 背景 | 识别色协调 | 卡片 / 记号 | 标题字体 |
| --- | --- | --- | --- | --- | --- | --- |
| 沈理青 | 清晨校园 | 晨光中的教学楼与树影 / 夜里亮灯的图书馆 | 薄荷到暖白的渐变，右上角一个淡绿光斑 | 0.3 | `tint` / `bar` | 无（正文字体） |
| 墨夜 | 深夜自习 | 窗外城市夜景与台灯 / 同一场景更暗 | 近黑渐变，带极淡的星点纹理 | 0.5 | `glass` / `dot` | 得意黑（Smiley Sans，OFL） |
| 海盐蓝 | 海风与纸飞机 | 海面、云和纸飞机 / 月光下的海面 | 冰蓝到白的渐变，云朵纹理 18% | 0.6 | `tint` / `icon`（纸飞机） | 站酷快乐体（OFL） |
| 樱粉 | 春日樱花道 | 樱花道和自行车 / 夜樱和路灯 | 淡粉到奶油的渐变，花瓣纹理 15% | 0.7 | `tint` / `icon`（花瓣） | 霞鹜文楷（OFL） |
| 纸感 | 书桌与手账 | 摊开的笔记本和钢笔 / 台灯下的书桌 | 米色纸张纹理 25%，没有渐变 | 0.4 | `solid` 加 1dp 描边 / `bar` | 霞鹜文楷（OFL） |
| 校园四季 | 学校四季实景 | 校园实景照片（需要维护者提供） | 渐变取自照片的主色 | 0.4 | `glass` / `dot` | 无 |
| 明风 · 晴蓝 | 角色主题 | 明风半身插画叠在首页 hero，"我"页用另一张姿势 / 夜晚版本 | 粉蓝渐变加云朵纹理，**不再放人物全身壁纸** | 0.7 | `tint` / `icon`（兔子发卡） | 站酷快乐体（OFL） |

"明风"是创作者明风OuO 的原创角色。用生成插画做的主题只能本地试用；投稿到商城、作为官方主题之前，需要拿到创作者的书面授权，并把许可写入 manifest 和许可清单。

## 6. 素材规格（交给素材生成）

| 素材 | 尺寸 | 格式 | 要求 |
| --- | --- | --- | --- |
| Hero（亮 / 暗各一） | 1080×960（9:8） | JPG 质量 88，≤ 2MB | 主体在右侧 60% 区域、垂直 25%–75% 之间；左上 40%×35% 区域保持干净、低对比（标题会叠在这里）；底部 20% 色彩简单，便于渐隐；不能有文字、水印、界面元素 |
| 纹理 | 512×512 | PNG，透明背景 | 必须能四方连续无缝平铺；元素稀疏（覆盖面积 ≤ 15%），单色或双色 |
| 贴纸 | 长边 ≤ 1024 | PNG，透明背景 | 有 2–4px 白色描边，边缘干净；每套 2–3 张，和 hero 同一画风 |
| 空状态 / 错误插画 | 800×800 | PNG，透明背景 | 主体居中，留 10% 边距；空状态表情平和，错误插画略带困惑但不负面 |
| 底栏图标 | 192×192 | PNG，透明背景 | 单色剪影（template 模式），线宽 ≥ 12px；常态描边、选中态填充；含义分别是首页、集市、课表、校园、我 |
| 区块记号 | 96×96 | PNG，透明背景 | 单色剪影 |
| 桌面图标 | 1024×1024 | 前景 PNG、背景色值、单色剪影 PNG | 主体在中间 66% 圆内；保留沈理校园的辨识度 |

## 7. 验收

- **对比验收**：每个阶段都提交"改版前 / 改版后"的九页明暗截图拼图（390×844），由维护者确认。
- **可读性**：页头叠字区域在亮暗两种模式下，文字对比度至少 4.5；`titleTone=auto` 对每张 hero 都要截图核对。
- **性能**：页头视差和渐隐不能让首页滚动出现超过 16ms 的 raster 帧；纹理平铺不能每帧重新解码。
- **兼容**：省略全部新字段的旧包，外观零变化；首批五套官方主题按第 5 节重做后，版本号加一，通过商城更新。
