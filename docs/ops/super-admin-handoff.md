# 生产超级管理员交接与账号注销

正式部署与发布批准见 [部署总入口](../../DEPLOY.md)。此入口处理已批准的生产超级管理员交接，原账号按现有账号注销规则永久匿名化。先记录明确的保留与注销账号 ID，核对保留账号有可用凭据，并保全受限的 PostgreSQL 与生产配置备份。

1. 确认当前正在使用的 `SUPER_ADMIN_ID` 来自受控生产配置。把种子登录标识切换到保留账号，重启并确认健康检查、身份核验和超管角色。把配置标识留在主机内。已有种子账号的应用密码由服务保留。
2. 使用经验证的提交构建 `./cmd/retire_super_admin`，按服务账号从生产运行目录执行。为使旧进程的会话缓存立即失效，在执行注销期间停止 Go 服务，提交完成后立即重新启动。

~~~bash
retire_super_admin -keep-id <保留账号ID> -retire-id <注销账号ID>
~~~

3. 确认原账号状态为 `cancelled`、角色为普通用户、刷新会话已撤销、注销审计已记录。核对保留账号在再次启动后仍是当前种子超管，并确认待处理数据清理任务。

注销与审计同一事务完成。提交前出错可回退配置；提交后保留新的种子配置，以免重建原登录身份。内容关联、必要审计与备份按 [留存台账](../retention-and-backup-inventory.md) 处理。
