# 2026-10-23 搜索问题与 Android 模拟器回归

> 后续修订：用户明确要求单字符也可搜索，最终规则已改为 **1 至 64 字符**。本文保留首次回归的历史记录，文中“仍限制 2 至 64 字符”及未提交时点的状态已被[单字符搜索补充报告](2026-10-23-single-character-search.md)替代；当前接口契约以 `server/API.md` 为准。模拟器已恢复默认线上 API，维护者随后明确授权推送。

## 结论与范围

“搜索 2 提示网络错误”的直接原因已确认：统一搜索接口要求关键词去除首尾空白后为 **2 至 64 个 Unicode 字符**，单独的 `2` 被服务端以 `400 bad_request` 拒绝；客户端原来把所有失败都渲染为“搜索失败，请检查网络后重试”。两字以上的正常关键词可以返回结果，无匹配时正常返回空列表。

本次修复输入校验、错误语义、搜索请求隔离和分页失败恢复，并修复模拟器回归中发现的校园页周次写死问题。没有改变服务端的关键词长度、公开数据范围、鉴权或限流规则。

用户已明确选择“只修改当前 SYLUlive-zhzh 仓库”。最初截图及模拟器中的 `com.luntan.luntan`（0.0.5）属于另一份客户端。本报告验证对象为当前仓库构建的 `com.example.shenliyuan`（1.7.6+1711）；安装时保留了模拟器中原有应用数据。用户要求使用 ADB 后，所有设备输入、截图、网络和显示状态切换均使用 ADB，不再操作桌面鼠标。

## Changed

- `client/lib/screens/search_results_screen.dart`：空输入、单字符、超过 64 字符和纯通配符在本地显示具体原因；可点击“修改关键词”继续输入。
- 使用现有 `AppFeedback.dioErrorMessage` 区分参数错误、权限错误、限流、服务端失败和真实断网，避免把异常对象直接展示给用户。
- 新查询、类型切换、排序切换和账号会话变化会使旧请求失效并取消旧网络请求；返回页面后不再提交过期结果。
- 分页失败保留已加载内容，在底部提供“重试加载更多”，不因继续滚动自动反复发送失败请求。完整解析一页后才提交结果，防止解析异常留下半页数据。
- 补充搜索和返回按钮的语义提示；错误内容可滚动，以适应键盘和大字号。
- `client/lib/widgets/campus/campus_header.dart`：周次、学期和进度读取现有校历；没有有效教学周时不显示虚构的周次和进度。校园页支持已有测试时钟传入标题组件。
- `server/API.md` 补充现有搜索输入规则、空结果与错误状态、匿名限流契约。
- 新增 25 项搜索测试及 9 项校园标题测试。
