# 主题制作与审核细则

本文面向三类读者：主题作者、商城审核员、官方主题的制作者。

- 格式、对比度规则与硬性校验规则以 [主题包格式契约](theme-pack-contract.md) 为准。
- 本文规定的是做出一套好主题的标准，以及审核时的判定依据。
- 第 1–4 节的内容要整理成作者可读的版本，放进主题工坊的"制作指南"页。

## 1. 制作流程（主题工坊）

1. **定主色**：选一个种子色，工坊会推导出全套 Token。先在亮色和暗色下各看一遍首页和课表，再决定要不要逐个微调 Token。
2. **调课表**：点"从种子色生成"，得到一套课程色板，然后在课表周视图里检查相邻课程能不能分得清。
3. **放壁纸**：先放全局壁纸。只有首页、课表、我三页确实需要不同的氛围时，才单独设置页面壁纸。每张壁纸都要用模糊和遮罩把文字区域压干净。
4. **调材质**：设置组件透明度和毛玻璃。壁纸越花，透明度就要越高（越接近 1.0）。
5. **换图标**（可选）：五个底栏图标要么全换，要么只换"首页"一个；不要只换其中两三个，否则风格会不统一。
6. **检查**：工坊对比度面板全绿；明暗两套都在九个首批页面上看过一遍。
7. **导出或投稿**：填写名称、简介、标签和许可，确认素材授权。

## 2. 配色细则

**硬性要求**：满足格式契约第 5 节的对比度阈值，商城投稿时会自动拒收不达标的主题。

以下各项由作者自查、审核员人工判断，工坊不做自动检测：

| 检查 | 规则 | 原因 |
| --- | --- | --- |
| 大面积背景的色度 | `background`、`surface`、`card` 在 HCT 空间的色度不超过 16 | 高饱和的大面积底色看久了容易累，也会让卡片层级糊成一片 |
| 亮色背景的亮度 | 亮色模式下 `background` 的 HCT 色调不低于 90 | 低于这个值，看起来像"灰掉的暗色"，而不是亮色 |
| 暗色背景的亮度 | 暗色模式下 `background` 的 HCT 色调不高于 12 | 同上，方向相反 |
| 主色与危险色 | `primary` 与 `#E54848` 的色相差至少 20°，或 `primary` 的色度不超过 20 | 避免普通按钮看起来像删除、警告操作 |
| 卡片层级 | `card` 与 `background` 的色调差，亮色至少为 2，暗色至少为 3；或者 `cardBorder` 与 `card` 的对比度至少为 1.3 | 卡片要能和背景分开 |
| 课程区分度 | 色板中相邻两个颜色的色相相差至少 25° | 相邻课程要能分清 |

推荐做法：

- 亮色背景用带一点主色倾向的暖白或冷白，不要用纯 `#FFFFFF` 作为页面底色。卡片可以用纯白。
- 暗色背景用色调 6–10 的深灰，并带轻微色相。纯黑 `#000000` 只用于明确定位为 OLED 的主题。
- 主色的色调：亮色模式 35–50，暗色模式 70–85。

## 3. 壁纸细则

| 项 | 要求 |
| --- | --- |
| 尺寸 | 竖屏推荐 1080×2340，横屏推荐 2340×1080。短边至少 720，长边至多 4096 |
| 文件 | 推荐 WebP，质量 80–85，单张控制在 1.5MB 以内。上限是 8MB |
| 安全区 | 竖屏顶部 12% 会被状态栏和顶栏遮挡，底部 14% 会被底栏遮挡。主体放在中间 74% 的区域内，并用 `focalX`／`focalY` 对准 |
| 文字区 | 壁纸本身不能带文字、水印、二维码或联系方式 |
| 首页 | 首页上有信息流卡片，画面花的图要加 `blur` 6–12，或者把组件透明度设到 0.9 以上 |
| 课表 | 课表上有网格和小字。推荐使用低对比、大色块的画面，`blur` 4–8，`scrim` 至少 0.2 |
| 我 | 顶部是头像和资料卡，画面主体要避开顶部 30% 的区域 |
| 明暗 | 暗色模式下的壁纸要单独提供更暗的版本；或者沿用同一张图，但 `scrim` 至少 0.35 |

## 4. 图标细则

| 项 | 要求 |
| --- | --- |
| 画布 | 192×192 透明背景。图形主体放在中间 144×144 的区域内 |
| 语义 | 每个槽位的图标必须能被认出原来的含义：首页＝家或主页，集市＝商店或购物，课表＝日历或课程表，校园＝建筑或校园，我＝人物 |
| 两态 | 常态与选中态必须能看出区别：选中态填充加常态描边，或者两态的形状不同。两张图完全相同会被拒收 |
| template 模式 | 只用到图标的 alpha 通道。图标要做成单色剪影，线宽至少 12px（按 192 画布计算），这样缩到 24dp 时依然清楚 |
| original 模式 | 彩色图标在亮色和暗色两种 `navBackground` 上都要清楚可辨，要用明暗两套预览分别检查 |
| 文字 | 图标里不能有文字 |
| 风格 | 五个图标的线宽、圆角、视觉重量要一致 |

## 5. 命名、描述与授权

**名称**：

- 不超过 20 个字符；
- 不能以"官方""沈理""沈阳理工"开头，这几个词留给 `official` 来源；
- 不能冒充其他作者；
- 不能带广告或联系方式。

**简介**：说明这套主题的风格和适用场景。不能出现链接、二维码、QQ 号、微信号或店铺信息。

**素材授权**：

- 投稿时必须勾选"我拥有全部素材的使用权"。
- 许可字段按实际情况选择：
  - 自己拍摄或绘制的作品：可以选任意许可；
  - 使用别人的作品：需要原作者授权，并在简介中注明来源；
  - 原创的同人作品：可以投稿；
  - 影视或动漫的截图、官方宣传图、商业插画、品牌标志：不予上架。
- 校徽、校名标识只能出现在官方主题里。

## 6. 内容红线

出现以下任意一项，直接拒绝；情节严重的，交给账号处理流程：

- 色情、性暗示、血腥暴力；
- 政治、宗教、歧视、仇恨相关内容；
- 广告、引流、联系方式、二维码、链接；
- 能识别出身份的他人照片（本人拍摄并取得同意的除外），以及学号、手机号、证件等个人信息；
- 冒充官方，或者冒充 App 的系统界面（例如在壁纸里画一个假的弹窗或按钮）；
- 抄袭他人在商城里已上架的主题（同样的壁纸加上同样的配色）。

## 7. 审核规程

### 7.1 每个投稿必做的检查

1. 在管理端审核页点"试用此主题"，开启全局试用会话，顶部会常驻"试用中"横条。从底栏依次切换首页、集市、课表、校园、我五个页签；再从"我"进入个人主页、设置，从首页进入 AI 助手和工具箱；在系统设置里切换明暗模式，把这九个页面再看一遍。
2. 检查过程中重点确认文字可读、控件颜色（按钮、开关、滑块）与主题一致。
   - 检查完成后，点横条上的"结束"，回到原外观，再返回审核页做出判定。
   - 如果中途重启了 App，试用会自动结束，需要重新进入审核页。
3. 逐张查看壁纸原图：放大检查边角有没有水印、文字、二维码。
4. 如果主题带底栏图标，核对五个槽位的语义和两态区别。
5. 核对名称、简介、标签与实际内容是否一致。
6. 如果是新版本，对照"与上一版的差异"面板，检查改动是否合理。

### 7.2 判定

- 通过：所有检查都符合要求。
- 拒绝：必须从下表中选择原因，可以再附加补充说明。作者看到的是"原因 + 补充说明"。

| 原因代码 | 作者看到的原因 |
| --- | --- |
| `contrast` | 部分页面的文字看不清，请提高文字与背景的对比度 |
| `wallpaper_text` | 壁纸含文字、水印、二维码或联系方式 |
| `copyright` | 素材授权不清，或使用了未授权的作品 |
| `content` | 内容不符合社区规范 |
| `icon_semantics` | 底栏图标无法辨认原含义，或两态没有区别 |
| `quality` | 画面模糊、拉伸、主体被遮挡等质量问题 |
| `metadata` | 名称、简介或标签与内容不符，或含广告 |
| `impersonation` | 冒充官方或他人 |
| `duplicate` | 与已上架的主题重复 |

- 审核时效目标：投稿后 48 小时内处理。

### 7.3 下架

已上架的主题被举报并核实违规后，下架整个版本族。下架原因从 7.2 节的原因表中选择，作者在"我的投稿"里能看到下架原因。

## 8. 官方主题制作细则

官方主题用主题工坊制作，并用维护者账号投稿，`source` 为 `official`。

每套官方主题必须满足以下全部要求：

- 工坊对比度面板全绿，第 2 节表格中的各项都满足；
- 明暗两套都完整提供；
- 九个首批页面在亮色和暗色下都截图，作为制作记录存档；
- 名称以外的文字（简介、标签）由维护者确认。

首批 6 套的起始参数如下，工坊中可以在此基础上微调：

| 名称 | 亮色种子 | 方案 | 关键覆盖 | 壁纸 | 图标 |
| --- | --- | --- | --- | --- | --- |
| 沈理青 | `#147C72` | 以内置默认值为基础，不走推导 | 亮色 `textSecondary` 改为 `#6E757C`，因为默认值 `#747B82` 在白卡片上只有 4.29。这是有意的视觉变化，需要单独验收 | 无 | 无 |
| 墨夜 | `#5B7C8A` | `neutral` | 暗色：`background` 为 `#000000`，`card` 为 `#0E1113`，`navBackground` 为 `#0A0C0D` | 无 | 无 |
| 海盐蓝 | `#2F7FD8` | `tonalSpot` | 亮色 `background` 为 `#F5F9FF`；色板为 8 色蓝绿系 | 无 | 无 |
| 樱粉 | `#C9617E` | `tonalSpot` | 亮色 `background` 为 `#FFF7F8` | 无 | 无 |
| 纸感 | `#3E6B4F` | `fidelity` | 亮色 `background` 为 `#F6F0E2`，`card` 为 `#FBF7EE`；圆角为 `compact` | 无 | 无 |
| 校园四季 | `#4E8A5A` | `tonalSpot` | 由壁纸取色后再微调 | 全局一张，首页、课表、我各一张，需维护者提供校园照片 | 全套 `template` 模式线性图标 |

前 5 套是纯配色主题，可以先上架。校园四季等照片到位后再制作。
