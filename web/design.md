## 当前方案：蓝白线框与内容分组（2026-11-03）

以用户提供的 v3.2 蓝白参考为起点。用户进一步明确，层次应来自组件外框、内部线条和内容关系。当前采用白色画布、清晰的中性轮廓线、统一圆角及间距。主内容按任务分组，字号与对齐表达阅读顺序。Web 与 Flutter 各自维护设计系统。

- 浅色画布与内容面使用白色。组件外框使用 `#dce1e9`，内部细分隔线使用 `--line-2`，文字使用中性灰。亮蓝承载品牌、链接、选中状态和主操作。参考蓝为 `#4070ff`；白字主按钮微调为 `#3867f5` 以满足 4.5:1 对比度，链接使用 `#315df2`。深色沿用同一角色，改为蓝黑表面与浅蓝文字。
- 桌面外壳的有效最大宽度默认 1376px，顶栏 65px；三栏为 214px 个人资料与导航、弹性信息流、296px 校园速览，栏间隔 26px。各页顶栏统一使用 1322px 上限，桌面预留滚动条位置，切页时标识和工具区保持对齐。首页与社区在三栏宽屏下将外壳（含两侧各 20px 留边）收至 1322px，让中间阅读列最大为 720px，栏间隔仍为 26px。1179px 以下隐藏右栏，窄桌面与集市继续保留已有图标导航收展和 220ms 位移。首屏使用问候、校园速报、发布输入框、文字筛选标签、公共帖子和连续信息流，不再使用大面积宣传横幅。
- 左侧依次为真实个人资料、社区、个人入口、校园板块和可展开的学习与校园服务；底部保留工具箱、反馈、个人主页及角色允许的管理入口。右栏为真实本机课表、校园公开资讯、服务端热门帖子与校园服务；未连接、加载、空数据、错误与重试均有明确显示。参考页的天气、活动、数量与帖子不作为业务数据。
- 帖子上方的置顶展示名称改为「公共帖子」，继续以服务端 `is_pinned` / `water_section_pinned` 决定展示范围；公共帖子可进入真实详情，不在普通信息流重复显示。已过期的全站置顶继续作为普通帖子展示，不改变服务端治理或权限。
- 信息流正文使用 15px / 1.8，帖子标题桌面 20px、手机 18px，首页问候 28px，投票页标题 32px。首页公共区域的辅助文字最低 12px，侧栏资讯标题 13px，发布提示 14px。每条帖子使用独立的 1px 外框、16px 圆角与 16px 卡间距，作者行、正文、配图及互动栏共用左边线。所有宽度均按作者、正文、配图、互动栏的顺序上下排列；用户明确保留图片在正文下方，不采用左右分栏。桌面首页与社区阅读列最大 720px，收紧作者与正文、正文与图片之间的间距。筛选栏与公共帖子各自保留完整边界。互动栏以细线分隔，点击高度至少 44px；卡片内容宽度达到 520px 时，点赞、评论和收藏紧凑靠左，分享靠右，选中与悬停时显示底色。首页问候作为页面标题，校园动态作为信息流分区标题。宽屏校园资讯集中在右栏，1179px 以下在主栏保留校园速报。长正文的全文入口独立于截断段落，发帖、互动与详情返回继续沿用已有实现。
- 头像直接使用用户接口的 `avatar`，板块使用 `/api/water/sections` 的 `avatar_url` 与 `icon_key`，站点标识使用已有服务器静态资源。资源统一通过 `asset()` 解析；加载失败回退到名字首字或后台配置图标，新 URL 不继承旧失败。
- 侧栏保持参考比例：资料卡约 196–210px，鼠标桌面板块显示五行；昵称、简介及板块名在原有宽度内省略。761px 以上桌面使用整栏粘附，适用于普通窗口高度；两侧分别在视口内溢出滚动，底部入口可用鼠标或键盘到达。右栏条目使用有界网格，资讯每行 84px、标题最多两行，标题与来源间距至少 5px，热榜每行 44px，长标题不能撑宽或撑高卡片；资讯至少 416px、热榜至少 304px，加载、错误重试及空数据保留同一框体，各卡片不随窗口高度被压缩。

- 全站模块与弹窗共用 `tokens.css` 与最后加载的 `src/commons.css`；基础控件继续在 `src/web-polish.css`，外壳及动效在 `src/social-shell.css` / `src/shell-motion.ts`。桌面新增数据呈现在 `src/campus-chrome.tsx`，不引入组件依赖或服务端接口。

## 登录与本机账号记录（2026-11-03）

登录弹窗桌面最大宽度 460px，使用站点图标、欢迎区、带图标的输入框、记住选项、整行主操作及注册入口组织内容。手机沿用全屏表单，输入字号 16px，密码显隐和历史记录操作区至少 44px，可在短屏滚动到提交按钮。首个焦点进入账号输入，方向下键展开历史账号并聚焦记录，第一次 Escape 收起列表，第二次关闭弹窗。

欢迎区采用图标、标题与底部分隔线组织留白；记住选项以独立细边界收拢，说明附锁形图标，主按钮有方向提示。历史账号提供数量、当前账号勾选和完整账号提示，支持方向键循环及 Home／End 定位；错误信息通过 aria-describedby 关联到输入框。

历史账号在表单内展开，最多最近 5 个，可逐条移除或清空；密码须额外选择，默认不保存。成功后按选择写入本机记录，失败保留输入并显示错误，存储不可用可继续手动登录。服务端尚未确认时关闭登录，不回填或保存迟到结果；已确认成功后的保存可在弹窗关闭后完成，显式移除始终优先于旧写入。账号切换与手动输入隔离解密结果，切换账号时重新隐藏密码；跨标签页删除会清理自动回填的旧密码。注册及找回流程保留既有接口和协议选择，返回登录时聚焦账号输入。保存与删除的边界以本地存储、隐私及留存台账为准。

实现入口为 `src/login-panel.tsx`、`src/login-history.ts` 和 `src/auth.css`。验收入口为 `e2e/login-history.spec.ts`、`src/login-history.test.ts` 与已有 Cookie／账号隔离测试。截图等待弹窗最终不透明状态，避免把既有 240ms 入场动效的中间帧作为最终画面。

## 设计判断

工作台、讨论与二手物品都属于日常使用界面。浅色使用白色与中性浅灰，深色使用炭黑与中性深灰；不再给整个页面染蓝。侧栏采用连续表面与一条右侧分隔线，搜索为浅灰胶囊；主要操作使用蓝色胶囊按钮。帖子以作者、正文、图片和互动栏组成连续信息流，默认不套浮起卡片，悬停时仅出现灰色表面。模块用留白和分隔线组织；去掉图标底托、彩色边线及常规阴影。右栏和商品仍保留细边框以表达明确分组。日程未知时保留紧凑连接提示，游客不显示个人统计的虚构零值。

已有业务骨架保留：Workbench 工作台、文章与评论、商品网格；集市导航的 208px → 64px 收展和内容位移不改变。桌面外壳最大宽度 1480px，社区阅读区填满分配列，与右栏保持 24px 间隔。首页是任务入口，社区是作者信息与内容，详情是文章及讨论，集市是搜索和商品目录。主页面共享同一控件体系。

## 组件规则

- 按钮：主按钮为蓝色胶囊配白字；次按钮实色表面与细边界；内容动作透明底。主要触控区域至少 44px，焦点即时出现。hover 与按下只改变填充，不移动内容。搜索入口、文字链接和右栏分区入口共用清晰的键盘焦点。disabled、pending、error 与 retry 保留原逻辑。
- 导航：融入连续页面表面，仅保留 1px 右侧边界，不套圆角外框；当前项为中性灰底与正文色。行宽扣除两侧 8px 留白，避免裁掉右端。行高及收展节奏不变，路由过渡中图标不纵向跳位，手机仍为不透明抽屉。
- 工作台：日程改为紧凑状态行与下划分隔线，连接按钮与文本并列；有本机资料后展示实际课程数。六个常用入口最小高度 48px，只有 20px 图标和名称，不加描边、阴影或图标底座；保留原按钮名和跳转，把更多首屏空间留给校园动态。
- 右栏：个人、分区与服务保留细边框分组，去掉顶部色条与阴影。游客展示登录收益及直接打开登录弹窗的按钮，不显示未获取的个人统计；登录后继续显示真实统计与个人主页链接。分区不用装饰性编号，数据从真实 API 读取。
- 社区：筛选为文字标签与选中下划线，搜索是独立表单；作者头像 40px，正文 16px，帖子间以细线分隔。默认内容表面连续，鼠标悬停仅给当前帖子加中性底色，避免每帖都套圆角容器。点赞、评论、收藏、分享保持统一操作区域，关注按钮使用浅底胶囊。
- 图片：单图按自身比例与大小展示，信息流最大高度 420px，移动端仍受容器宽度限制；不拉伸小图、不裁切原图，不填充宽大空框。保留原图预览、加载失败和重试。多图及评论图片保持既有逻辑。
- 集市：标题、搜索面板、分类和商品网格依次排列。商品卡的图片贴齐外框，去掉图片外的第二层边界；状态置于图片角上，标题两行、价格与卖家分区，卖家信息前使用细分隔线。商品方图、筛选参数和详情返回行为保留。
- 商品详情：金额与状态仍在作者之后、图片之前；联系方式保持现有访问规则。帖子正文、讨论和作者右栏采用同一组件语言。
- 发布弹窗：复用主按钮、表单和焦点规则，取消旧渐变与背景模糊；表单使用 16px 间距，不再叠加字段外边距。关闭按钮为 44px，短内容弹窗首屏可见提交动作，长表单在弹窗内部滚动；关闭后恢复触发按钮的焦点。

## 动效与状态门禁

### 助手与机器人管理

`/web/connected-apps` 及助手草稿确认页接入当前社区广场主题，复用 `tokens.css` 的蓝色主操作、实色内容面、文字、边框与圆角，不再单独覆盖全站强调色或提供局部毛玻璃开关。历史外观偏好不再读取或写入，系统高对比模式继续使用系统画布与文字颜色。

机器人状态、服务端开放与本人专用授权分别呈现，状态同时有文字与图形，不用颜色代替权限事实。保留设备代码核对、权限选择、草稿确认、失败重试、保存禁用及账号切换隔离；内部信息行不重复套卡片。

保留 220ms 导航收展和 FLIP 内容位移。最终网格宽度先确定，再执行位移，动画期间不反复换列。快速反向从当前可见位置继续；键盘与减少动态效果直接切换，视口改变时取消未完成位移。颜色／边界微反馈为 120ms；减少动态效果关闭这些过渡。

`e2e/market-presentation.spec.ts` 验证图片边界、筛选、加载／空态／失败／重试、权限、真实参数和逐帧收展；`e2e/community-presentation.spec.ts` 验证互动及评论；`e2e/web-visual-theme.spec.ts` 检查四个主页面、八种宽度、深浅主题的 64 个渲染状态，包含选定文本与控件对比度、图片边界、键盘焦点及首屏主功能。右栏和商品保留明确边界；导航检查右侧分隔线、无圆角外框及无阴影，入口检查无描边、无阴影及无图标底座。桌面导航点击区域至少 44px 且不越出侧栏，入口文字不得越出按钮。另检查 375／1440px、深浅色的四个发布弹窗状态，包括控件对比、焦点、无渐变、Escape 关闭与焦点返回。截图使用显式测试数据，不作为自动更新固定基线，也不等于全站无障碍认证。
