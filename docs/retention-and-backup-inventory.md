# 保存、备份与日志台账

0.5.0 的 `managed_bots.revision/runtime_json` 仅保留当前规则版本和最新非正文执行元数据，沿机器人关系生命周期及 PostgreSQL 备份保留；两分钟是执行占用有效期，不是物理删除期限。撤权／注销立即阻断更新，已发内容和审计沿原留存。本机恢复索引最多500项，调度时间及发言账本沿对应公共库保留，停用后独立清理，不随阅读正文的7天清理删除。

多用户插件沿用本机授权留存：每位发起人的安装 ID 文件在插件数据目录保留，Token 只存安全凭据库或进程内存，解绑只影响本人。授权结果等待任务最多512项、最长10分钟，结束或重载清除；群披露确认最多256项、5分钟，消费或重载失效，不保存查询正文。群名单现在可授予本人签到入口，但不能授予别人的账号或 scope；详细默认规则以[多用户授权](ai/astrbot-multi-user-authorization.md)为准。
