# 本地存储台账

Windows 本机机器人守护在 `D:\AI\QQ\guardian` 保存 `health.json`（最近一次固定健康状态）、`state.json`（失败计数、恢复时间、由本机启动的进程ID/创建时间）、安装摘要、OS锁及有限错误码日志；不保存聊天/模型/学校正文或Token。恢复时间记录每次检查只保留一小时窗口，状态保留到用户移除；守护日志为512KB、最多3个轮转备份。进程恢复标准输出沿本机服务日志规则保留，重启前超过2MB的文件轮转一份，可能受服务自身输出规则影响；不将服务原始日志上传仓库。任务计划只保存程序路径和无凭据参数，使用当前交互用户，读取的管理凭据沿原本机受保护配置保存；退出App不停止守护，卸载需按[守护运维入口](ops/local-bot-guardian.md)移除任务／启动项及本机记录。

逐账号任务每30秒清理已打开公共库的过期原文／向量；停机、停用且库未打开时不保证物理删除，重新打开或检索前按原7天上限清理，过期内容不进入模型。运行元数据与发言账本的保留独立，见下文及留存台账。

AstrBot 0.5.0 的 `<origin及平台哈希>.accounts.json` 仅登记不透明凭据槽哈希和随机 installation_id，无 QQ 号、Token 或密码；最多500项，随本机插件数据保留。重启恢复已有安全凭据，损坏索引不覆盖。创建者旧槽与公共库保留，普通账号及不同 bot 的公共库按槽哈希与 bot ID 隔离；`runtime_schedule` 只存 bot ID 与下一轮时间，沿公开库保留，清正文不清调度／发言账本。App/Web 不读取本机文件；服务端撤权不远程删除副本，停用后由部署者独立清理。

二课双密码在 Flutter 客户端通过 `DeviceCredentialStore` 写入系统安全存储，沿用学号指纹键；二课页在认证成功后按用户的保存选择写入，校园 Agent 与个人数据中心可复用。取消保存时仅供当前页面会话使用，Flutter Web 不持久化。独立 React Web 教务助手的可选本机保存规则见上表。二课页“清除已保存密码”或个人数据中心清除本机数据会删除该凭据；单独清除二课成绩缓存不会删除密码。历史 `erke_cas_pwd`、`erke_erke_pwd` 明文偏好仅清理，不迁移。

AstrBot 多用户插件在插件数据目录按身份哈希保存随机 installation_id，不存 Token；每位发起人的凭据只放 OS 安全凭据库，无安全后端时仅进程内存。旧 owner 凭据槽不变。绑定结果等待与群披露确认只在内存，重载失效，不保存结果正文；范围和留存见[多用户授权](ai/astrbot-multi-user-authorization.md)及[留存台账](retention-and-backup-inventory.md)。

Web 已授权助手页的成绩/二课同步预览、确认勾选和请求状态仅在当前页面内存中，切号/类型变化或离页丢弃，不新增 localStorage/IndexedDB 副本；已有教务助手本机资料仍按上表用户选择保存。本人确认后的服务端同步副本与保留边界见[隐私台账](privacy-data-inventory.md)，不能把页面关闭视为删除已上传副本。

教务自动绑定进度按 `academic_lifecycle_<identity>_binding_sync` 保存，只表示待同步／已同步／拒绝；历史 declared/bound 标记不能代替服务端权限。学校会话仍只在本机加密保存；自动登记核验时经 HTTPS 临时发送最小 Cookie／必要会话前缀，不在服务端保存。服务端身份缺失时，恢复会话、原入口重连和课表读取均可触发补交。云端解绑、不同学号或当前配置不一致时阻止旧设备恢复身份；旧队列冲突不阻断对相同有效云端学号的独立核验。
