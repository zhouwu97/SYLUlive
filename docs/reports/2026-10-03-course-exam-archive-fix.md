# 课表学期与公共存档修复（2026-10-03）

基准提交：`b568aebbd27705d0621f6ef43042994ca5e927ae`。风险 R2：涉及用户教务展示数据的公共文件保存、旧版 Android 兼容与异步学期隔离。范围仅客户端，没有本次生产操作。

## 问题与修改

1. 课表存档菜单的刷新入口没有传递 `currentTerm.providerTermId`；兼容仓储将本科 `3/12` 学期码转换成 `1/2`，但本科 Provider 学期列表使用 `year|3/12`。修复为传递学校真实 ID；无 ID 的兼容入口按 `localYear/localSemester` 匹配。研究生 ID 保持严格校验，不能猜测。请求期间切换账号/学期时丢弃旧结果，获取失败或空课表保留现有数据。
2. 原先保存课表只保留 App 内存档；导出尝试直接写公共路径，失败后转到私有目录。用户主动保存时现在同时生成公共 JSON 副本；公开写入失败仍保留 App 内存档，提示从存档右侧导出重试。防重复保存期间禁用输入及操作，并显示保存中。
3. 公共写入统一使用 Android 10+ MediaStore.Downloads 的 `RELATIVE_PATH/IS_PENDING`。写入完成后发布，写入失败删除半成品，返回系统实际文件名。目标目录为 `Download/沈理校园/课表存档/` 与 `Download/沈理校园/考试存档/`。Android 9 及以下使用系统文件保存选择器，取消不报成功；不请求广泛存储权限。
4. 考试页原先直接写 `Download/沈理考试`，一并换成公共存档服务；保留导出 JSON 格式与导入兼容。导出捕获所选学期及考试列表快照，避免对话框期间数据变化影响导出；输入控制器在对话框退场后释放。当前页面使用本地安排、手动/AI 辅助导入，没有从学校取考试日程的入口，因此不能将本次修复表述为新增教务考试拉取。
5. 分享使用同内容的临时文件；只在用户主动操作后产生。公共 JSON 不包含学校密码、Cookie、Token 或原始 HTML，公共副本由用户自行删除。已同步 README、隐私台账与留存台账。

Android 公共下载实现依据：[Android 官方共享媒体存储文档](https://developer.android.com/training/data-storage/shared/media)。

## 人工验收与恢复

修复代码需要打入新 APK；此前 `1.7.6+1710` 内测包不包含本次修复。安装新包后，在课表存档中保存一个新存档，或对旧存档点击导出；随后在文件管理器查看 `Download/沈理校园/课表存档`。考试页导出后查看 `考试存档`，再导入该 JSON 验证安排一致。还需 Android 9 保存选择器与 Android 10+ 文件管理器、同名保存、取消、存储不足/写入失败、学校真实账号刷新验收。

回滚客户端代码不删除用户公共文件；App 内历史存档仍可读取，公共副本可由文件管理器删除。未覆盖或删除此前生成的 APK。
