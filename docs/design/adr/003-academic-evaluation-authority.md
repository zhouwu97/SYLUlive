# 003 — 学科评价只有一份可编辑主记录

状态：accepted（2026-11-04，维护者明确要求课表评价与教师评价作为同一业务）。生产迁移与发布仍需单独授权。

## 决策

`course_evaluation_submissions` 是评价的唯一可编辑主记录，持有正文、星级、归属、版本与审核状态。教师详情和课表入口共用既有提交服务。`source` 只记录入口或历史来源，不定义另一种评价。

`teacher_ratings` 保留为已发布评价的兼容投影，维持既有公开评价 ID、投票、举报、治理与旧链接；它不再拥有独立的用户写入流程。该表的评分与正文由提交服务在同一事务内派生。不能把两份查询结果拼成“我的内容”作为最终一致性方案。

历史教师评价通过显式、可预览、可重复执行的迁移关联到主记录。新建历史主记录完整保留正文、评分、创建与更新时间；已有主记录仅在归属和内容一致时修复关联。冲突不按时间猜测覆盖，不截断正文，不删除评价、投票或举报。两个方向的关联均验证所有者，跨账号关联阻止执行。

“我的内容”和总数均从主记录读取。旧公开评价兼容删除接口先验证所有者，再在一个事务里移除主记录与公开投影；公开评价保留既有软删除审计，不能先解绑其他用户的主记录。

## 兼容与执行

不新增第三份评价存储，不更改公开评价 ID；现有表名与接口地址保留。历史来源为 `legacy_teacher`，使用真实主记录 ID 和同一编辑表单。两个入口正文上限统一为旧教师入口支持的 500 字，迁移不截断历史文字。

迁移工具默认只读预览，执行要求备份确认及预览指纹；数据变化、归属冲突或内容冲突时整批拒绝写入。发布前在隔离数据库验证旧数据、重复执行、失败回滚、两入口更新、删除及个人统计。生产发布以当前生产基线重新形成候选，不能用旧分支二进制覆盖已上线功能。

## 恢复

迁移只新增主记录及修复双向关联，保留旧公开行及内容，旧版本也可读取新增主记录。执行前保存数据库与旧二进制备份。失败自动回滚事务；执行成功后发生新编辑时禁止按旧快照覆盖回滚数据，应用回退保留主记录与兼容投影，必要的数据修复按迁移预览逐项复核。
