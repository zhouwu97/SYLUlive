# SYLUlive 官方学业政策知识库 v0.6

本版修复“补考成绩怎么算”“挂科怎么办”无法回答的问题。2026年7月26日修订：补考与重修必须分开；2004年D/F口径只能作为历史版本引用；在没有已核验正式文件之前，不得给出统一的补考成绩合成公式。

核心变化：

- 将“挂科、补考、二考、重修、刷分、实践课不合格”映射为六类确定性意图，与服务端 `policy_intent.go` 同名；
- 每个意图定义必须覆盖的证据组 `required_document_groups`，不再只做文档类型过滤；
- 历史资料策略从布尔值改为三档 `none / fallback / required`；
- 新增补考与重修边界的当前业务口径材料，并明确它不确立成绩合成公式；
- 2004年D/F、绩点1/0只保留为历史材料，引用必须标注历史版本；
- 增加检索、生成、版本冲突和来源卡去重测试。

生产发布顺序：

1. 撤销或supersede v0.1-v0.5；
2. 导入 `SYLUlive_AI官方全文导入包_v0.6.jsonl`；
3. 优先导入并发布 `SYLUlive_AI现行补考口径导入_v0.6.json`，撤销冲突的旧规则卡；
4. 按 `SYLUlive_校园政策RAG与Skill修复方案.md` 修改服务端；
5. **重新索引全部 v0.6 文档**：入库时的 embedding 文本已改为“标题 + 文档类型 + 部门 + 章节标题 + 正文”，
   只更新 Go 代码不会改变生产库里的旧向量。逐个文档执行
   `shenliyuan-ai-kb reindex --document-id <ID>`，或调用 `POST /api/admin/ai/knowledge/:id/reindex`；
6. 跑 `SYLUlive_政策规则测试用例_v0.6.json`；
7. 再做生产问答抽测。

注意：只导入v0.6数据但不改检索与提示词，仍可能出现召回不准或不推理；不重新索引则文档类型和章节标题不会进入向量。
