- UI 基准：按用户要求恢复的首个 Web 提交 `90765c82dba5a265cc1ff5e1e6fe216df461e961`。
- 范围与风险：R1；Web 首页、社区、帖子详情、个人主页、公共图片展示及手机导航。保留初版青绿色视觉，未修改服务端或 Flutter。

## 设计检查

| Before | After | Why |
| --- | --- | --- |
| 390px 手机首帖约在 y=357px | 约 y=264px；标题与发布同排，搜索与分区同排 | 减少顶部占用，保留正文和图片空间 |
| 手机单图沿用两列，约 158×150px，cover 裁切 | 单图独立展示；宽图约 334×145px，近方图可接近内容区宽度；所有帖子图片 contain 居中 | 完整展示真实图片，避免缩成小缩略图 |
| 桌面单图固定三列中的一列，约 260×150px | 依据原始比例展示，横图可到 540px 宽；详情阅读区最多 920px，图片可进一步放大 | 图片清楚，正文行长也可控 |
| 无标题帖子复制前 50 字作为标题，又显示正文 | 有真实标题才显示标题 | 去掉重复文字 |
| 列表作者只显示昵称首字 | 使用服务器头像；缺失或失败时回退昵称首字 | 不伪造头像，保留可识别的失败状态 |
| 个人页 `.profile-head` 缺少布局，访客页只有一行提示 | 明确头像、昵称、统计、操作和内容结构；访客使用紧凑登录卡 | 与帖子风格统一，避免空白占位 |
| 评论缺乏统一布局 | 使用真实头像、作者和时间，图片共用完整预览 | 评论更容易区分与阅读 |
| 手机抽屉没有键盘焦点管理 | 展开后接管焦点、循环 Tab、Esc 归还；Ctrl+K 先关抽屉再开搜索 | 防止焦点落到遮罩后的内容或两个弹层争抢焦点 |
| 未连接课表也显示“0 今日课程” | 显示“尚未连接”，已有资料才显示课程数量 | 区分未知状态和真实零数据 |

## 实现范围

- 新增 `web/src/post-media.tsx`，统一真实头像、服务器图片变体回源、损坏图片提示、等比展示及键盘图片预览。
- `community.tsx`、`pages.tsx`、`profile.tsx` 共用上述组件。多图按数量排列，评论及个人内容使用相同展示规则。
- 增加 `/user/:id` 公开个人页，仅消费既有公开用户、帖子、闲置、关注及粉丝接口。统计仅展示服务端确实返回的数值。
- 保留既有个人编辑、安全、隐私、发布等接口流程。未登录的关注、我的发布、收藏显示登录提示，避免 disabled 查询一直显示加载。
- 样式集中补充到既有 `styles.css`，没有恢复被用户舍弃的橙色侧栏设计。
