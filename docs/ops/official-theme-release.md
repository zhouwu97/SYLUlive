# 内置官方主题发布

经发布负责人批准分发的内置主题，可随 Android 包发布并通过运维命令登记到在线商城。社区投稿和 App 内的官方投稿继续由独立管理员审核。官方发布命令没有 HTTP 接口，使用已有的超级管理员账号署名。

先执行 [部署总入口](../../DEPLOY.md) 和 [发布前回归清单](../../RELEASE_CHECKLIST.md)。发布记录写明素材授权、主题源包、App 提交、服务器提交和负责署名的账号。使用与部署提交一致的源码构建发布命令，按生产 Go 服务账号运行，复用运行目录的数据库和上传卷配置。

~~~bash
go build -o /tmp/publish_official_theme ./cmd/publish_official_theme
# 在部署运行目录由服务账号执行已授权的发布
publish_official_theme -package <获授权的内置主题文件> -author-id <超级管理员ID> -release-commit <App完整SHA>
~~~

用 `-description` 可为商城简介补充素材署名。登记复用商城的规范化校验，保留内置包的版本族 ID 和版本，发布记录与审计同一事务提交。同一个 App SHA 只登记一次，重复执行返回原记录。已下架或撤回的记录保留原状态。

通过公开官方目录、详情、两张预览图和版本化下载验收。需要停止分发时，使用商城既有下架入口。回滚 Go 服务前检查主题举报：如果同一用户有针对多个主题的待处理举报，旧版的非 UUID 唯一索引无法加载这些记录，此时保留数据和主题表并采用向前修复。
