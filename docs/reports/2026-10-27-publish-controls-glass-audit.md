# 发布表单、筛选控件和按钮玻璃材质复验

- 日期：2026-10-27
- 基准：`dfed0e53e6b414fb82dbacd91240340288a734b9`，分支 `xianzai`
- 风险：R1。调整客户端表面绘制、裁剪、前景颜色与导航布局；没有修改上传、鉴权、提交或治理接口。
- 环境：Windows、仓库当前 Flutter SDK、Pixel 8 / Android API 37.1 模拟器，ADB `emulator-5554`。

## Changed

1. 发布出售页内部 `DecoratedBox` 不再遮挡自定义壁纸；简洁模式仍使用普通页面底色。
2. 水帖版块选择、图片添加入口、投票标题/说明/选项/图片入口和反馈输入框使用共用玻璃材质。卡片内已有表面的输入控件不再叠加不透明填充。
3. 三类发布页的底部材质包含安全区；发布页系统手势栏透明，避免底部黑色断层。
4. `AppChoiceChip` 清除 RawChip 内部 Material 的默认 canvas 填充，解决选中色被白底覆盖、白字难辨和边缘叠层。
5. 新增 `appGlassButtonStyle`，在原按钮内部绘制玻璃底面并遵守原按钮形状。相关资料编辑、版块管理、公告、治理、试卷管理、反馈与发布按钮接入，前景文字和图标保持实色；禁用状态保留原语义。
6. `FrostedGlass` 使用 `BlendMode.src`，避免弹层淡入等 saveLayer 场景再次合成已过滤的底面。
7. 治理导航改为可横向滚动，避免“疑似推荐”数量徽标挤出布局；深色选中标签使用已有深色强调色。反馈空状态和输入提示提高可读性。

## Preserved

- 发布表单草稿、字数限制、图片选择与上传、排序、校验、提交防重、失败重试、账号会话隔离和取消行为沿用现有实现。
- 原生按钮的回调、键盘激活、焦点与禁用状态继续由原控件负责。
- 毛玻璃关闭时返回原按钮样式；简洁模式不删除已选择的背景图片。个人主页业务封面仍可显示。
- 工作区现有官网与 Web 修改保留，提交仅包含本报告列明的客户端修改、测试和本报告。
