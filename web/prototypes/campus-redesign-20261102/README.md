# 沈理校园 Web 独立改版原型

打开 `index.html` 对比三版，不需要安装依赖或启动服务。HTML 使用同目录 CSS / JS，分享时请保留整个目录。

## 功能分析

依据 `web/README.md`、`web/src/main.tsx` 的 navigation、`pages.tsx`、`catalog.tsx` 梳理，不引用现有视觉方案或 App 设计规范。原网页同时承担学习查询、社区互动和校园服务，单层长导航的任务优先级不足。三版分别探索三种主次关系，而非只替换颜色。

- A：钴蓝、冷白、侧栏；以今日课程和高频查询为第一任务，适合长期桌面工作台。
- B：米白纸感、朱红、宋体标题、横向栏目；以校园内容为核心，适合资讯门户。
- C：柔紫、青柠、圆角内容卡片；强调分享与连接，适合社区主导产品。

保留全部 17 个现有顶级功能的入口。首页、课表、社区、集市、AI 有专门布局；其他模块是二级入口和说明弹窗，没有实现完整业务。管理入口仅展示权限说明。

## 可体验范围

功能搜索、社区分类、点赞与收藏切换、评论、发布表单、商品弹窗、课表周次与课程弹窗、模拟 AI 回答、连接说明。顶部状态选择器展示 loading / empty / error / retry / permission。AI 延迟回调绑定页面版本，切走后不会写入新页面。

所有数据虚构；页面不发起业务请求、不保存数据、不读取真实教务或账号、不进行实际发布交易。刷新后交互重置。独立目录新增，不修改现有业务代码或现有未提交修改。
