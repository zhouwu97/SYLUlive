# Web 图文发帖与草稿契约

适用范围：Web 首页、社区、集市、手机浮动发布入口及已发布帖子的编辑。视觉样式沿当前 Web 主题，不冻结配色、尺寸或动效数值。

## 任务与入口

- 新帖入口进入独立页面 `/web/compose`，集市使用 `?board=2`；旧帖编辑进入 `/web/post/:id/edit`。页面由 `web/src/post-editor-page.tsx` 承接，所有图文入口复用 `web/src/post-composer.tsx`，继续通过既有帖子和上传 API 完成写入。
- 发布位置在顶部即可确认；标题、正文、图片沿同一列填写，集市交易信息保留在内容下方。正文自动增高，编辑区域使用一处滚动，底部操作持续可达。桌面和手机都不把发帖放入弹窗。
- 桌面评论点击输入条后原地展开，楼中楼回复在对应评论下面展开；复用 `ReplyComposer` 的上传、表情及权限判断，不进入发帖页面。收起或 Escape 保留当前页面中的文字与图片，重新展开可继续；成功发送、离开详情或切号后清除。表情面板先处理 Escape，再次按下才收起编辑器；Ctrl/Cmd+Enter 复用点击发布的验证链路，输入法组合期间不触发。手机继续使用原来的输入弹框与底部入口。
- 从列表进入时记录站内来源与历史位置，返回保留原有筛选和阅读位置；直达页面使用社区、集市或原帖作为返回位置。Escape 只处理原有弹框，不退出发帖页。
- 直达编辑页须读取帖子及服务端 `viewer_permissions.can_edit`，分别处理加载、失败重试、无帖子及无权限；不能只依赖列表隐藏编辑按钮。
- 编辑区提供正文、可选标题、图片及预览；集市使用物品名称、类型、价格或预算、联系方式。标题上限 120 个 Unicode 字符，正文上限 10000 个，与服务端创建接口一致。
- 从社区分区进入时使用当前分区；没有指定时优先校园生活，缺少该分区才使用当前可用的首个分区。不得在编辑时静默替换一个已经不可用的原分区。
- 编辑器顶部持续说明发布位置。底部操作在长文和图片滚动期间保持可达，Ctrl/Cmd+Enter 与点击发布使用同一验证链路，输入法组合期间不触发快捷提交。

## 分区和内容状态

- 分区加载、失败、无数据、不可用与可用须分别表达；失败可重读，正文和图片不丢失。无法确认有效分区时禁止发布。
- 空白正文不发送；标题、正文、集市价格、联系方式和图片要求在上传前验证，服务端仍是权限与内容规则的最终判断方。
- 预览不上传、不发布，保留文字换行和图片顺序；预览只说明阅读布局，不保证替代服务端审核后的最终结果。
- 协议或社区规则门禁保留当前内容；用户明确确认后仍需重新提交，禁止自动重放原写入。
- 错误与确认提示必须进入当前可见滚动区域，不能只存在于 DOM 或通过按钮变色表达。

## 本页草稿

- 草稿包括文字、选中类型、集市字段、保留的原图片、待上传 File 及发布结果是否待核对；仅存当前标签页运行内存。
- 暂存返回、站内导航和浏览器后退保留当前标签页草稿，重新进入对应的新帖或编辑入口可继续；在发帖页打开其他弹框不丢失内容。
- 不写 localStorage、sessionStorage、IndexedDB，不跨设备同步。刷新/离开站点清除；有未发布内容时浏览器离开提示用于提醒，不能宣称已经持久保存。
- 切号/退出会清理草稿，A→B→A 不能复用原会话；发布成功和本人清空后删除对应草稿。

## 图片与编辑

- 总数最多 9 张，JPG/PNG/GIF，单张不超过 10 MiB；选择、拖入及粘贴共用校验，非法项不删除原来有效的选择。
- 未选图时提供添加入口，选图后展示缩略图及顺序操作。一般发布提示可展开阅读；错误、权限、社区规则确认和发布结果待核对提示须直接可见。
- 支持删除及键盘前后排序；对象 URL 随选择变化和组件卸载释放。
- 编辑必须展示并保留原图；只有图片发生变化才提交替换字段。新增图片与保留的原图共同提交，移除所有原图时明确发送空列表。原图片缺少可信文件编号时禁止猜测编号或静默丢弃。
- 上传成功编号在当前会话和同一个 File 对象内复用，批量部分成功也保留成功项；重试只上传剩余项。取消或切号后不得降级回退上传，也不得继续发布。

## 提交、取消和恢复

1. 校验当前内容与权限前置 → 上传未上传的图片 → 创建/更新帖子 → 核对有效帖子编号 → 刷新列表/详情 → 展示结果。
2. 上传期间锁定编辑与发布，可停止上传并返回、保留草稿；离开发帖页中止本页上传，旧上传结果不得触发后续写入。
3. 发布确认期间锁定重复提交，页内返回和快捷搜索不能中断确认。浏览器后退或其他站内导航仍可能离开页面，业务请求发出前须暂存待核对状态；中止本页等待不能冒充取消了服务端写入，重开先核对。等待超时结束后同样转为结果待核对状态。
4. 网络中断、5xx 或成功响应缺少编号时，不声称未发布或再次自动提交；保留内容，提供“查看我的发布”和本人核对后的继续编辑入口。
5. 当前帖子接口没有通用创建幂等键；页面保护不能被描述为服务端幂等保证。结果不明确时必须先核对，不能靠自动重试消除不确定性。
6. 仅在返回有效帖子编号时进入详情；审核等待状态与直接发布成功分开反馈，不导航到 `undefined`。

本机数据边界见[本地存储台账](../local-storage-inventory.md)；验证、风险与发布门禁见[开发与交付规范](../../DEVELOPMENT_STANDARD.md)。
