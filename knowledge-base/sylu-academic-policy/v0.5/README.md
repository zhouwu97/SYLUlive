# SYLUlive 官方学业政策知识库 v0.5

## 内容

- 6份沈阳理工大学正式文件全文或完整表单字段；
- 国家学生管理和学士学位框架正文；
- 已取得的学校官方专业介绍正文；
- 面向后端的确定性政策规则；
- 规则回归测试用例；
- 来源文件SHA-256和版本废止关系；
- 尚待补齐的第二课堂、综测、一般违纪处分、学位细则和培养方案清单。

## 生产导入

1. 将v0.1-v0.4撤销发布或标记为superseded。
2. 导入 `SYLUlive_AI官方全文导入包_v0.5.jsonl`。
   `SYLUlive_AI待核验补充导入包_v0.5.jsonl` 必须作为低权重、待核验资料独立导入，不能并入官方全文包。
3. 执行检查、索引和人工抽查。
4. 规则引擎读取 `SYLUlive_确定性政策规则_v0.5.json`。
5. 运行 `SYLUlive_政策规则测试用例_v0.5.json` 中的回归用例。
6. 涉及退学、开除、处分、学位和转专业最终资格时，必须保留人工复核入口。

## 重要边界

- 竞赛A/B/C/D/E分类仍需具体认定办法才能映射到每个赛事。
- 第二课堂、综测、一般违纪处分和各专业培养方案尚未补齐。
- 转专业文件是2020年完整正式文件，但仍需持续检查是否出现新版本。
- 补考成绩公式来自用户截图，当前仅供解释并等待教务处正式文件核验；确定性计算保持禁用。
