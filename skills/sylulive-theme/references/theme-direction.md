# 主题方向：角色设定、母题与组件分工

## 从 B 站学到的做法

- **手机主题（如阿罗娜主题）**：作者把每个图标逐张重绘；开机动画、设置页头、通知图标、通话界面、安装等待页都放了角色或光环母题；配色只用角色身上的白和天蓝。宣传语就是「随处可见的角色元素」。
- **B 站装扮套装**：同一个角色拆成主题顶栏背景、5 个底栏动作图标、表情包、加载动画、点赞特效、评论区装扮、头像框和粉丝卡片。大图负责认人，小组件负责氛围；每个小组件都是同一个 Q 版的不同动作或表情。
- **反面例子**：只换一张风景壁纸、只在一角放一个人物、图标用通用线性图标改色。这样用户感受不到「这是某个角色的主题」。

## `concept/character.md` 模板

```markdown
# <角色名>

## 身份锚点
- A：refs/raw/...（三视图）  B：refs/raw/...（成熟比例）

## 标志物清单（生成时逐项写进提示词，验收时逐项打勾）
| 部位 | 准确描述 | 常见错误 |
| 头发 | 深蓝到浅蓝渐变的波浪长发，发尾浅 | 画成纯色、直发 |
| 呆毛 | 头顶一根弯曲呆毛 | 漏画 |
| 耳朵 | 头两侧鲸鱼鳍形耳，深蓝外侧白色内侧 | 画成猫耳、精灵耳 |
| ... |

## 性格与梗 → 可画的动作或表情
| 性格／梗 | 动作或表情 | 用在哪 |
| 傲娇 | 双手叉腰扭头、脸红 | 我的页头、错误插画 |
| 聪明但懒 | 趴在桌上半睁眼、抱着书打哈欠 | 校园页头、空态 |
| 爱吃白饭 | 双手捧大碗白饭、嘴角沾饭粒 | 首页页头、贴纸 |
| 叫用户「鱼片」 | 指着屏幕外、递便签 | 我的页头贴纸 |

## 禁区
- 不画成写实比例、不加不属于她的配饰、不改变发色渐变方向……
```

## `concept/theme.md` 模板

```markdown
# 主题概念
一句话：<例：「吃白饭的大肥鱼在校园里摸鱼的一天」>

## 母题（1–2 个，贯穿全套）
- 主母题：鲸尾剪影 → 区块记号、底栏选中态、纹理
- 辅母题：水泡／饭粒 → 背景光斑、纹理点缀

## 配色（从锚点图取色）
| 角色 | 色值 | 用途 |
| 发色深 | #1F4E9C | seedColor（明） |
| 发色浅 | #7DB7F0 | 渐变、seedColor（暗） |
| 围裙白 | #F7F9FF | 背景 |
| 点缀 | … | 光斑 |

## 明暗两套的差别
明：白天、窗边、浅蓝；暗：夜晚书桌、深海蓝、台灯暖光点缀。
```

## 组件分工原则

- **3 个页头**是 3 个不同场景，各体现一个性格；不能是同一张立绘的 3 种裁切。明暗可以是同一场景的白天和夜晚版本。
- **壁纸**是舞台，不是主角：渐变加母题纹样，加一个小 Q 版。不要用风景照或另一张大立绘。
- **贴纸**是性格表情包：4–6 个动作都不同，并且都能在 48px 下认出来。
- **底栏图标**先保证语义，再加角色味：统一线宽和圆角，选中态加母题（例如鲸尾托着图标，或小头像探出图标）。
- **空态、错误插画**要带情绪，并和文案语义对得上（空、出错）。
- **母题**至少出现在 4 处：纹理、区块记号、底栏选中态、一个角饰。
