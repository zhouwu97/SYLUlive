# 试卷库筛选栏单行布局设计

## 目标

在 Android 手机端缩小试卷库筛选控件，并将学年、学期、类型和排序四项固定在同一行展示；学年下拉仅提供“全部学年”和最近 3 个学年。

## 范围

仅调整 `ExamPaperToolbar` 的展示和选项生成逻辑。不改服务端接口、试卷查询参数、搜索防抖、列表加载及筛选回调。

## 布局

- 搜索框保持现有尺寸和位置。
- 四个筛选控件始终使用 `Row`，不再在窄屏换行。
- 控件高度由 32px 收紧到 28px，文字、内边距、下拉箭头和控件间距同步缩小。
- 四项按 4:4:4:3 的弹性比例分配可用宽度，保证“全部学年”“全部学期”“全部类型”和“最新”在常用 Android 手机宽度下完整可见。
- 不引入横向滚动；筛选统计和清除操作仍位于筛选栏下方。

## 学年选项

- 工具栏接收的学年列表维持既有倒序约定。
- 学年下拉显示“全部学年”以及列表前 3 项。
- 已选学年不在最近 3 项时，仍保留该值作为当前下拉值，避免界面状态和查询条件脱节。

## 组件边界与数据流

`ExamPaperLibraryScreen` 继续提供完整学年列表和筛选回调。`ExamPaperToolbar` 负责将列表裁剪为可展示选项，并将用户选择原样回调给页面；查询请求格式不变。

## 异常与兼容性

- 学年列表少于 3 项时，显示实际可用项。
- 学年列表为空时，只显示“全部学年”。
- 使用紧凑的文字和比例宽度，防止手机窄屏发生溢出；现有大屏也沿用同一行布局。

## 验收与测试

- 组件测试验证 320px 宽度下四个筛选项垂直坐标一致，且无渲染异常。
- 组件测试展开学年下拉，验证仅包含“全部学年”和最近 3 个学年。
- 执行相关 Flutter 组件和页面回归测试。
- 仅使用 Android Studio 模拟器安装运行，打开试卷库并验证筛选单行、学年数量和下拉选择行为；不使用 Web、浏览器或其他验证方式。
