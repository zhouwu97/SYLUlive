# SYLUlive 官方学业政策知识库 v0.6

状态：候选版本。仓库不声明该版本已经进入生产；以管理员 API 只读清单和发布审计为准。

本版修复“补考成绩怎么算”“挂科怎么办”无法回答的问题。

核心变化：

- 将“挂科、补考、二考、重修、刷分”映射为正式制度术语；
- 新增当前规则 + 历史细则的组合规则卡；
- 收录《教学管理文件汇编》中二考D/F、绩点1/0、开学初二考、未过转重修的原文要点；
- 明确该细节来自2004年历史校内文件，不覆盖2024/2025现行文件；
- 增加检索、生成、版本冲突和来源卡去重测试；
- 提供服务端RAG与个人Skill的完整修改方案。

安全发布顺序：

1. 校验 `release-manifest.v0.6.json` 与 `SYLUlive_AI官方全文导入包_v0.6.jsonl` 的内容和元数据 hash；
2. 运行纯本地 dry-run，确认重复、冲突、空章节和待核验项；
3. 对候选包执行真实 LangChain 分块与 embedding 契约检查；
4. 通过管理员 API 导入并索引候选，旧 published 文档此时保持不变；
5. 所有候选完成检查后，在单事务中 publish/supersede；禁止先批量撤销 v0.1-v0.5；
6. 跑 `SYLUlive_政策规则测试用例_v0.6.json` 和生产问答抽测；
7. 异常时使用发布记录执行原子回滚。

详细命令、备份、抽测和回滚步骤见 `docs/ai/t08-knowledge-base-v06-release-runbook.md`。

## 待核验边界

- 当前二次考试成绩记载口径或当期教务通知仍缺失；2004 年 D/F、绩点 1/0 只能作为明确标注的历史口径。
- 第二课堂、综合测评、一般违纪处分、现行校级学位细则和各专业培养方案仍不完整。
- 这些项目保留在清单与 dry-run 的 `unresolved_items` 中，不得由 AI 推断为空或已解决。

注意：只导入v0.6数据但不改检索与提示词，仍可能出现召回不准或不推理。
