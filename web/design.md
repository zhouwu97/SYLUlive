# 沈理校园 Web：内容与日常操作

状态：2026-10-09 第五轮本地视觉迭代。用户认为第四轮模板感太强，要求减少 AI 味。保留此前要求的导航外框和已认可的收展结构，减少嵌套容器、色块和通用宣传文案。适用范围仅为 `web/`；Flutter 继续遵循其冻结设计系统。此前方案仅作为历史记录。

## 设计判断

工作台、讨论与二手物品都属于日常使用界面。灰色页面承托白色内容，标题和正文使用深灰，少量蓝色标记链接与主要操作。去掉大面积紫色、卡片套卡片、图标底座和重复箭头。没有课程资料时显示紧凑的连接提示，不把未知课表显示成醒目的零。常用功能仅保留名称和图标，帖子与商品图片成为主要视觉内容。模块用边界划分，内部用文字与分隔线划分。

已有业务骨架保留：Workbench 工作台、文章与评论、商品网格；集市导航的 208px → 64px 收展和内容位移不改变。首页是任务入口，社区是作者信息与内容，详情是文章及讨论，集市是搜索和商品目录。主页面共享同一控件体系。

## 唯一维护入口

执行变量在 [tokens.css](tokens.css)，组件视觉在 [web-polish.css](src/web-polish.css)。该样式文件已整理为一套规则，避免不同迭代叠加覆盖。外壳几何与动效仍在 [social-shell.css](src/social-shell.css) 和 [shell-motion.ts](src/shell-motion.ts)。其他业务模块复用现有语义变量。

深色保持相同强调色系，重新定义表面和文字亮度，不仅反转背景。错误和成功继续使用各自语义色及文字。弹窗和页面共用变量。

标题和正文使用 Segoe UI + 苹方／微软雅黑本机回退，数字使用 Segoe UI 与等宽数字。中文标题不使用大幅负字距和超重字重。页面标题 26px，详情标题 22px、正文 16px，其他字号为 12／14／15／18／20px。间距按 4px 基础递增，控件圆角 6px，内容面板 8px，图片 6px。常规组件不使用阴影。字体有意采用本机回退，避免加载远程中文字体时闪烁，不保证跨系统字形完全一致。

## 组件规则

- 按钮：主按钮实色；次按钮白底与细边界；内容动作透明底。主要触控区域至少 44px，焦点即时出现。hover 改变色彩或边界，不移动内容。disabled、pending、error 与 retry 保留原逻辑。
- 导航：白色背景、1px 边框和 8px 圆角组成完整面板，桌面上下留 16px；当前项为浅灰底与深色文字。行宽扣除两侧 8px 留白，避免旧的 100% 宽度叠加外边距后裁掉右端。行高及收展节奏不变，路由过渡中图标不纵向跳位，手机仍为抽屉。
- 工作台：日程改为紧凑状态栏，连接按钮与文本并列；有本机资料后展示实际课程数。六个常用入口各自有细边框，但父层不再重复套框，移除同义说明和箭头。保留原按钮名和跳转。
- 右栏：个人、分区与服务模块共用有边框的白色表面；标题为普通文字与下划分隔线，个人数字之间使用竖线，分区不用装饰性编号。作者与相关帖子仍从真实 API 读取，不补虚构内容。
- 社区：筛选为文字标签与选中下划线，搜索是独立表单；帖子中的作者、正文、图片与互动具有清楚间距。点赞、评论、收藏、分享采用统一图标和操作区域。
- 图片：单图按自身比例与大小展示，上限控制阅读长度，去掉宽大灰色空框；保留原图预览、加载失败和重试。多图及评论图片保持既有逻辑。
- 集市：标题、搜索面板、分类和商品网格依次排列。商品卡的图片贴齐外框，去掉图片外的第二层边界；状态置于图片角上，标题两行、价格与卖家分区，卖家信息前使用细分隔线。商品方图、筛选参数和详情返回行为保留。
- 商品详情：金额与状态仍在作者之后、图片之前；联系方式保持现有访问规则。帖子正文、讨论和作者右栏采用同一组件语言。
- 发布弹窗：复用主按钮、表单和焦点规则，取消旧渐变与背景模糊；表单使用 16px 间距，不再叠加字段外边距。关闭按钮为 44px，短内容弹窗首屏可见提交动作，长表单在弹窗内部滚动；关闭后恢复触发按钮的焦点。

## 动效与状态门禁

保留 220ms 导航收展和 FLIP 内容位移。最终网格宽度先确定，再执行位移，动画期间不反复换列。快速反向从当前可见位置继续；键盘与减少动态效果直接切换，视口改变时取消未完成位移。颜色／边界微反馈为 120ms；减少动态效果关闭这些过渡。

`e2e/market-presentation.spec.ts` 验证图片边界、筛选、加载／空态／失败／重试、权限、真实参数和逐帧收展；`e2e/community-presentation.spec.ts` 验证互动及评论；`e2e/web-visual-theme.spec.ts` 检查四个主页面、八种宽度、深浅主题的 64 个渲染状态，包含选定文本与控件对比度、图片边界、键盘焦点及首屏主功能。导航、实际入口按钮、右栏模块和商品卡必须有背景和边框；桌面导航点击区域至少 44px 且不越出面板；入口文字不得越出按钮。另检查 375／1440px、深浅色的 4 个发布弹窗状态，包括控件对比、焦点、无渐变、Escape 关闭与焦点返回。截图使用显式测试数据，不作为自动更新固定基线，也不等于全站无障碍认证。

## 学习来源与采用范围

2026-10-09 实际打开用户提供的 [UI UX Pro Max 风格区](https://uupm.cc/#styles)，查看教育平台与 Customer Support CRM 演示，并读取其公开 [styles.csv](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/src/ui-ux-pro-max/data/styles.csv) 与 [colors.csv](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/src/ui-ux-pro-max/data/colors.csv)。

采用 Minimalism 的单一强调色和层级规则，以及 Soft UI Evolution 的柔和边界、清晰焦点与对比要求；针对校园的中文密度和真实内容自行组合。示例中的营销布局、演示数字、插图、字体和多色方案没有直接搬入产品。未安装该项目，也未执行其脚本。

第四轮补读 [Fluent 2 Material](https://fluent2.microsoft.design/material)、[Shapes](https://fluent2.microsoft.design/shapes) 与 [Elevation](https://fluent2.microsoft.design/elevation/)。采用实色表面、填充／描边区分容器和轻度层级；没有引入半透明材质或 Fluent 依赖。颜色和校园组件为本项目自定，不宣称与 Fluent 产品完全一致。

历史设计记录保留于 `docs/reports/`；本文件维护当前方案。新增业务状态应扩展命名语义，不在各页面自行定义另一套全局主色。

第五轮实际查看 [V2EX](https://www.v2ex.com/) 的列表密度、普通文字导航和模块内部的分隔方式，并对照用户此前提供的贴吧与闲鱼截图。采用内容先于装饰、单层容器和紧凑工具入口；保留本项目的图片流与商品网格，没有搬用站点品牌或内容。
