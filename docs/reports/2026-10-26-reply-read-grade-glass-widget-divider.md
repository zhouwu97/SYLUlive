# 回复已读同步、成绩卡片和超大字号小组件复验

- 日期：2026-10-26。
- 风险：通知消费与账号隔离为 R2；成绩页、小组件排版为 R1。
- 环境：Windows Flutter debug；ADB Pixel 8 / Android API 37.1。保留现有工作区改动，未提交、推送或部署。

## Changed（修改）

### 成绩页与学期选择

- 课程成绩条目原先直接绘制实色 Container，未进入统一玻璃组件；改用 AppCardSurface，保留原有分数、绩点、学位课状态、内边距与点击行为。
- 开启毛玻璃时，成绩列表和学期列表关闭逐项 RepaintBoundary，采用项目现有的滚动玻璃采样策略。
- 同一学年下的学期条目增加 8dp 留白，避免第一、第二学期卡片贴合。保留已有侧栏玻璃适配。

### 回复通知

- 通知页原先会跳过已标记为已读的记录；现在再次进入历史回复仍校准应用内提醒及系统通知。历史记录本身保留。
- 所有回复入口传入捕获的接收账号，并使用稳定的账号会话代次判断异步回执。普通资料刷新不再使已成功的回执失效；退出、换号仍使旧请求失效。
- 服务端旧版成功响应缺少 read_receipt 时，沿用服务层精确匹配通知 ID / 回复 ID 的兼容路径，补齐原生同步所需账号上下文。不降级为全部已读。
- 通知页退出后，成功请求仍刷新首页状态；重复点击、历史通知重复消费不会误减其他回复数量，未命中当前列表的回执重新查询未读。
- Android 记录最小化的已展示通知映射，支持启动器或 SDK 丢失 extras 后精确清除；只匹配回执所属账号和业务通知／回复。保留私信和其他通知，处理系统 ID 复用、撤销及延迟到达。
- 映射最多 2000 条，30 天过期，消费或撤销时移除。隐私台账同步更新；未新增权限、第三方服务或消息正文存储。

### 小组件与复验发现

- 课表、考试的原生 4×2 超大字号布局删除两栏中间的装饰竖线，Flutter 预览同步改为空白间距；保留课程侧边色条。
- 复验日志发现头像昵称截取单个 UTF-16 码元的问题。CachedAvatar 改为截取完整字素，避免 emoji 昵称占位触发绘制异常；增加 emoji、组合 emoji 和组合重音字符的回归测试。

## Preserved（保留）

- 保留既有毛玻璃、Web、官网及其他未提交修改；未重置或清理工作区。
- 保留成绩计算、教务凭证与缓存、学期切换逻辑、二维码及业务状态。
- 不清空通知历史、不将其他账号或其他回复设为已读、不发送测试消息。
- 复验结束恢复浅色、自定义背景、标准 100% 字号，保留毛玻璃开关；原有两个桌面课表组件及其校园蓝／超大字号／半透明设置保持不变。

### ADB 实际渲染和读链路

- 通知页进入指定回复成功。实际旧服务对帖子／回复组合请求返回 400，客户端随后通过通知列表匹配 ID，再提交成功；原生私有已读存储收到相应通知 ID、回复 ID，未写全部已读水位。
- 原有 2×2、4×2 课表组件实机截图确认：4×2 中间竖线消失，主题、字号及透明背景保留（home-after.png）。
- 成绩卡片浅色／深色自定义背景均显示玻璃；上下滚动未观察到白边或材质突变。简洁模式浅色／深色隐藏壁纸，课程文字与成绩可读（grades-open.png、grades-scroll.png、grades-dark.png、grades-clean-dark.png、grades-clean-light.png）。
- 学期选择同年两行实际相隔约 21 个屏幕像素，对应 8dp（semesters-after.png）。
- 恢复后的自定义背景成绩页截图：grades-restored-final.png。自动教务更新期间保留原课程列表和进度提示，没有布局溢出。

## Deferred（验证边界）

- 设备远程推送关闭，系统中没有待清理的真实回复通知；没有人为启用推送或发送消息。因此没有宣称真实系统推送已在这次 ADB 操作中消失。原生通知取消和首页正未读状态由上述自动测试覆盖，仍需下一条真实回复推送复验跨入口联动。
- 未穷举其他厂商桌面；Android RemoteViews 半透明材质不等于所有启动器都支持实时壁纸模糊。
- 不以本次定向结果宣称整库静态分析零警告，也不以全量测试结果覆盖之后的未运行增量；成绩与头像最后改动分别通过定向验证。
